    Chapter 07. 그래프로 말하는 데이터 — 데이터 시각화 기초¶

    Part 2 | [1권] 데이터 리터러시의 기초

    🎯 이 장에서 배우는 것¶

    • 막대그래프, 꺾은선그래프, 원그래프, 산점도의 특성과 적합한 사용 상황을 구분할 수 있다
    • 데이터의 종류에 따라 어떤 그래프가 적합한지 스스로 판단할 수 있다
    • 스프레드시트(또는 Python)를 활용하여 데이터에 맞는 그래프를 직접 만들 수 있다
    • 잘못된 시각화 사례를 분석하고, 데이터를 왜곡 없이 표현하는 원칙을 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기: 아래 두 가지 방법 중, 어느 쪽이 더 빨리 이해되나요?

    방법 A — 숫자만 보기 - 1학년 봉사 시간: 12시간 - 2학년 봉사 시간: 25시간 - 3학년 봉사 시간: 18시간 - 4학년 봉사 시간: 30시간

    방법 B — 막대그래프로 보기

    1학년 ████████████ 12
2학년 █████████████████████████ 25
3학년 ██████████████████ 18
4학년 ██████████████████████████████ 30

    대부분의 사람은 방법 B를 보는 순간 "4학년이 가장 많구나!"라는 사실을 0.5초 만에 파악합니다. 반면 방법 A는 숫자 네 개를 하나씩 비교해야 하죠.

    이것이 데이터 시각화(Data Visualization) 의 힘입니다. 숫자 더미를 한눈에 이해할 수 있는 그림으로 바꾸는 기술입니다.

    우리는 매일 뉴스, SNS, 발표 자료에서 그래프를 접합니다. 그래프를 만들 수 있는 사람은 자기 주장을 설득력 있게 전달하고, 그래프를 읽을 수 있는 사람은 거짓 정보에 속지 않습니다. 이번 장에서 그 두 가지 능력을 모두 익혀봅시다.

    📚 핵심 개념¶

    개념 1: 막대그래프 📊 — "누가 더 큰가?"를 비교할 때¶

    1. 비유로 시작

    체육 시간에 반 친구들의 키를 비교한다고 상상해 보세요. 친구들을 나란히 세우면 누가 큰지 바로 보이죠? 막대그래프는 바로 이 "나란히 세워서 비교하기"입니다.

    2. 정확한 정의

    막대그래프(Bar Chart) 는 각 항목(카테고리)의 값을 막대의 길이(높이) 로 표현하는 그래프입니다. 막대가 길수록 값이 크다는 뜻이죠.

    3. 이럴 때 사용해요 - 학급별 평균 점수 비교 - 과일별 판매량 비교 - 나라별 인구수 비교 - 핵심: 서로 다른 항목(카테고리)의 크기를 비교할 때

    알아보기: 막대그래프에는 세로 막대와 가로 막대 두 종류가 있습니다. 항목 이름이 길면(예: "초콜릿 아이스크림") 가로 막대가 읽기 편합니다.

    개념 2: 꺾은선그래프 📈 — "시간에 따라 어떻게 변했나?"를 볼 때¶

    1. 비유로 시작

    감기에 걸렸을 때 체온을 아침, 점심, 저녁으로 재서 기록해 본 적 있나요? 점들을 선으로 연결하면 "열이 올라가는 중인지, 내려가는 중인지" 한눈에 보입니다. 이것이 꺾은선그래프입니다.

    2. 정확한 정의

    꺾은선그래프(Line Chart) 는 시간의 흐름에 따른 값의 변화 추세(트렌드) 를 점과 선으로 표현하는 그래프입니다.

    3. 이럴 때 사용해요 - 일주일간 기온 변화 - 월별 용돈 지출 추이 - 연도별 학교 학생 수 변화 - 핵심: 시간 순서에 따른 변화(추세)를 보여줄 때

    알아보기: 꺾은선그래프의 X축(가로축)에는 반드시 시간 순서가 와야 합니다. 순서가 없는 항목(예: 좋아하는 색깔)에는 적합하지 않아요.

    개념 3: 원그래프 🥧 — "전체에서 차지하는 비율"을 볼 때¶

    1. 비유로 시작

    피자 한 판을 네 명이서 나눠 먹는다고 해봅시다. 누가 몇 조각 먹었는지를 보여주기 딱 좋은 그래프가 원그래프입니다. 전체 피자(100%)에서 각자가 차지하는 비율을 보여주니까요.

    2. 정확한 정의

    원그래프(Pie Chart) 는 전체를 100%로 놓고, 각 항목이 차지하는 비율(%) 을 부채꼴 크기로 표현하는 그래프입니다.

    3. 이럴 때 사용해요 - 반 학생들의 혈액형 비율 - 한 달 용돈 지출 항목별 비율 - 설문조사 응답 비율 - 핵심: 전체 대비 각 부분의 비율을 보여줄 때

    ⚠️ 주의: 항목이 6개 이상이면 원그래프가 복잡해져서 오히려 읽기 어렵습니다. 그럴 때는 막대그래프가 더 낫습니다.

    개념 4: 산점도 ⚬ — "두 가지 사이에 관계가 있을까?"를 볼 때¶

    1. 비유로 시작

    "공부 시간이 길수록 시험 점수가 높을까?" 궁금할 때, 친구들 각각의 공부 시간(X)과 점수(Y)를 좌표 위에 점으로 찍어보세요. 점들이 오른쪽 위로 올라가는 패턴이 보이면 "관계가 있다!"고 말할 수 있습니다.

    2. 정확한 정의

    산점도(Scatter Plot) 는 두 개의 수치 데이터를 각각 X축과 Y축에 놓고, 개별 데이터를 점(dot) 으로 찍어 두 변수 사이의 관계(상관관계) 를 탐색하는 그래프입니다.

    3. 이럴 때 사용해요 - 키와 몸무게의 관계 - 공부 시간과 성적의 관계 - 기온과 아이스크림 판매량의 관계 - 핵심: 두 수치 변수 사이의 관계(패턴)를 탐색할 때

    🗺️ 그래프 유형 선택 가이드¶

    어떤 그래프를 골라야 할지 헷갈린다면 아래 흐름도를 따라가 보세요.

    flowchart TD A["내가 보여주고 싶은 것은?"] --> B{"항목 간\n크기 비교?"} A --> C{"시간에 따른\n변화 추세?"} A --> D{"전체 대비\n비율?"} A --> E{"두 변수의\n관계?"} B -->|Yes| F["📊 막대그래프"] C -->|Yes| G["📈 꺾은선그래프"] D -->|Yes| H["🥧 원그래프"] E -->|Yes| I["⚬ 산점도"]

    정리하기: 그래프를 고를 때 가장 중요한 질문은 "내가 무엇을 보여주고 싶은가?" 입니다. 비교 → 막대, 추세 → 꺾은선, 비율 → 원, 관계 → 산점도. 이 네 가지만 기억하면 대부분의 상황을 커버할 수 있습니다!

    🔨 따라하기: Python으로 그래프 만들기¶

    이전 차시에서 정리한 "우리 반 데이터"를 그래프로 바꿔봅시다. Python의 matplotlib 라이브러리를 사용합니다.

    Step 1: 라이브러리 불러오기¶

    import matplotlib.pyplot as plt

# 한글 폰트 설정 (환경에 따라 다를 수 있음)
plt.rcParams['font.family'] = 'Malgun Gothic'  # Windows
# plt.rcParams['font.family'] = 'AppleGothic'  # Mac
plt.rcParams['axes.unicode_minus'] = False

    matplotlib은 Python에서 가장 많이 쓰이는 그래프 라이브러리입니다. plt라는 별명으로 불러오는 것이 관례입니다.

    Step 2: 막대그래프 — 과목별 평균 점수 비교¶

    subjects = ['국어', '영어', '수학', '과학', '사회']
scores = [82, 75, 90, 68, 85]

plt.figure(figsize=(8, 5))
plt.bar(subjects, scores, color='steelblue')
plt.title('우리 반 과목별 평균 점수')
plt.xlabel('과목')
plt.ylabel('평균 점수')
plt.ylim(0, 100)  # Y축 범위를 0~100으로 설정
plt.show()

    알아보기: plt.ylim(0, 100)으로 Y축을 0부터 시작하게 했습니다. 이것이 왜 중요한지는 뒤에서 "나쁜 그래프" 파트에서 배웁니다!

    Step 3: 꺾은선그래프 — 월별 기온 변화¶

    months = ['1월', '2월', '3월', '4월', '5월', '6월']
temps = [-2, 0, 7, 14, 20, 25]

plt.figure(figsize=(8, 5))
plt.plot(months, temps, marker='o', color='tomato', linewidth=2)
plt.title('서울 월별 평균 기온 (2024)')
plt.xlabel('월')
plt.ylabel('평균 기온 (°C)')
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()

    marker='o'는 각 데이터 점에 동그라미를 찍어주고, grid(True)는 눈금선을 추가합니다. 추세를 읽기가 훨씬 쉬워지죠.

    Step 4: 원그래프 — 용돈 지출 비율¶

    categories = ['간식', '문구', '교통', '저축', '기타']
amounts = [35, 15, 20, 20, 10]
colors = ['#FF9999', '#66B2FF', '#99FF99', '#FFCC99', '#C0C0C0']

plt.figure(figsize=(7, 7))
plt.pie(amounts, labels=categories, colors=colors,
        autopct='%1.0f%%', startangle=90)
plt.title('한 달 용돈 지출 비율')
plt.show()

    autopct='%1.0f%%'는 각 조각에 퍼센트를 자동으로 표시해 줍니다. 전체 합이 100이 되도록 데이터를 준비하는 것이 포인트입니다.

    Step 5: 산점도 — 공부 시간과 성적의 관계¶

    study_hours = [1, 2, 2, 3, 3, 4, 5, 5, 6, 7]
test_scores = [45, 55, 50, 60, 65, 70, 80, 75, 85, 92]

plt.figure(figsize=(8, 5))
plt.scatter(study_hours, test_scores, color='mediumseagreen', s=80)
plt.title('공부 시간과 시험 점수의 관계')
plt.xlabel('공부 시간 (시간)')
plt.ylabel('시험 점수')
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()

    점들이 왼쪽 아래에서 오른쪽 위로 올라가는 패턴이 보이나요? 이것을 양의 상관관계라고 합니다. 공부 시간이 늘수록 점수도 함께 올라가는 경향이 있다는 뜻이죠.

    Step 6: ⚠️ "나쁜 그래프" 체험하기 — Y축 조작¶

    같은 데이터인데, Y축의 시작점만 바꿔볼까요?

    scores = [82, 75, 90, 68, 85]
subjects = ['국어', '영어', '수학', '과학', '사회']

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 정직한 그래프: Y축 0에서 시작
axes[0].bar(subjects, scores, color='steelblue')
axes[0].set_ylim(0, 100)
axes[0].set_title('✅ 정직한 그래프 (Y축: 0~100)')
axes[0].set_ylabel('평균 점수')

# 왜곡된 그래프: Y축 60에서 시작
axes[1].bar(subjects, scores, color='indianred')
axes[1].set_ylim(60, 95)
axes[1].set_title('❌ 왜곡된 그래프 (Y축: 60~95)')
axes[1].set_ylabel('평균 점수')

plt.tight_layout()
plt.show()

    생각해보기: 오른쪽 그래프를 보면 과학(68점)이 마치 바닥인 것처럼 보이고, 수학(90점)과의 차이가 엄청나 보입니다. 하지만 실제로는 22점 차이일 뿐이죠. Y축을 0에서 시작하지 않으면 차이가 과장됩니다!

    📝 전체 코드¶

    아래 코드를 복사해서 한 번에 실행하면 네 가지 그래프를 모두 볼 수 있습니다.

    import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 1) 막대그래프
subjects = ['국어', '영어', '수학', '과학', '사회']
scores = [82, 75, 90, 68, 85]
axes[0, 0].bar(subjects, scores, color='steelblue')
axes[0, 0].set_title('📊 과목별 평균 점수')
axes[0, 0].set_ylim(0, 100)

# 2) 꺾은선그래프
months = ['1월', '2월', '3월', '4월', '5월', '6월']
temps = [-2, 0, 7, 14, 20, 25]
axes[0, 1].plot(months, temps, marker='o', color='tomato', linewidth=2)
axes[0, 1].set_title('📈 서울 월별 평균 기온')
axes[0, 1].grid(True, linestyle='--', alpha=0.5)

# 3) 원그래프
categories = ['간식', '문구', '교통', '저축', '기타']
amounts = [35, 15, 20, 20, 10]
colors = ['#FF9999', '#66B2FF', '#99FF99', '#FFCC99', '#C0C0C0']
axes[1, 0].pie(amounts, labels=categories, colors=colors,
               autopct='%1.0f%%', startangle=90)
axes[1, 0].set_title('🥧 한 달 용돈 지출 비율')

# 4) 산점도
study = [1, 2, 2, 3, 3, 4, 5, 5, 6, 7]
score = [45, 55, 50, 60, 65, 70, 80, 75, 85, 92]
axes[1, 1].scatter(study, score, color='mediumseagreen', s=80)
axes[1, 1].set_title('⚬ 공부 시간 vs 시험 점수')
axes[1, 1].set_xlabel('공부 시간')
axes[1, 1].set_ylabel('시험 점수')
axes[1, 1].grid(True, linestyle='--', alpha=0.5)

plt.tight_layout()
plt.suptitle('데이터 시각화 4가지 핵심 그래프', fontsize=16, y=1.02)
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: "일단 원그래프로 그리자!"¶

    원그래프는 비율을 보여줄 때만 적합합니다. "각 반의 학생 수 비교"처럼 크기를 비교하는 상황에서 원그래프를 쓰면 차이를 정확히 파악하기 어렵습니다. → 막대그래프를 쓰세요.

    실수 2: Y축을 0에서 시작하지 않기¶

    앞서 체험했듯이, Y축 시작점을 올리면 작은 차이도 거대한 차이처럼 보입니다. 특히 뉴스에서 이 트릭을 자주 사용하니 주의하세요! → 막대그래프의 Y축은 반드시 0에서 시작하세요.

    실수 3: 색을 너무 많이 쓰기¶

    무지개처럼 알록달록한 그래프는 예쁘지만, 핵심 정보가 묻힙니다. → 강조하고 싶은 항목 1~2개만 눈에 띄는 색으로, 나머지는 회색 계열로 처리하면 메시지가 명확해집니다.

    실수 4: 3D 효과 남용¶

    3D로 만든 원그래프는 앞쪽 조각이 뒤쪽보다 커 보이는 원근 왜곡이 생깁니다. 실제로 같은 비율이어도 위치에 따라 다르게 느껴지죠. → 2D 그래프를 기본으로 사용하세요.

    실수 5: 그래프에 제목·축 레이블 빠뜨리기¶

    제목도 없고 축 설명도 없는 그래프는 "이 숫자가 뭐지?" 라는 혼란을 줍니다. → 제목(title), X축 레이블(xlabel), Y축 레이블(ylabel) 은 항상 넣으세요.
