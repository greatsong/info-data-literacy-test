    Chapter 05. 데이터는 어디에나 있다 — 데이터의 유형과 수집¶

    Part 2 | [1권] 데이터 리터러시의 기초

    🎯 이 장에서 배우는 것¶

    • 정량적 데이터와 정성적 데이터의 차이를 구분하고 각각의 예시를 제시할 수 있다
    • 구조화된 데이터와 비구조화된 데이터의 개념을 이해하고 분류할 수 있다
    • 설문조사를 직접 설계하여 데이터를 수집할 수 있다
    • 공공데이터포털에서 원하는 데이터를 찾아 다운로드할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    오늘 아침에 일어나서 지금까지, 여러분이 "만들어낸" 데이터는 몇 개일까요?

    잠깐 떠올려 봅시다.

    • ⏰ 알람을 끈 시간
    • 🚶 스마트폰이 기록한 걸음 수
    • 🔍 검색창에 입력한 단어들
    • 💬 친구에게 보낸 메시지 수
    • 🎵 스트리밍으로 들은 음악 목록

    이 모든 것이 데이터입니다. 한 사람이 하루에 만들어내는 디지털 데이터는 평균 1.7MB 이상이라고 합니다. 문서 파일 수백 장에 해당하는 양이죠.

    하지만 데이터가 많다고 해서 자동으로 유용한 정보가 되는 것은 아닙니다. 냉장고에 재료가 가득해도 어떤 재료가 있는지, 어떻게 분류하는지 모르면 요리를 할 수 없는 것과 같습니다.

    이 장에서는 데이터를 종류별로 구분하는 눈을 기르고, 직접 데이터를 수집하는 방법을 배웁니다. 이것은 데이터를 다루는 모든 활동의 첫걸음입니다.

    📚 핵심 개념¶

    개념 1: 정량적 데이터 vs 정성적 데이터¶

    🍳 비유로 시작하기

    요리 레시피를 생각해 봅시다.

    • "소금 5g을 넣는다" → 숫자로 딱 떨어지는 정보
    • "간이 살짝 부족한 느낌이다" → 느낌이나 판단으로 표현된 정보

    데이터도 마찬가지로 두 가지 성격이 있습니다.

    📖 정확한 정의

    • 정량적 데이터(Quantitative Data): 숫자로 측정하거나 셀 수 있는 데이터. 크기를 비교하거나 계산할 수 있습니다.
    • 정성적 데이터(Qualitative Data): 범주, 이름, 의견 등 숫자가 아닌 말(텍스트)로 표현되는 데이터. 분류하거나 설명할 때 사용합니다.

    ✅ 예시로 확인

    • 정량적 데이터: 키 172cm, 시험 점수 85점, 등교 시간 8시 15분, 하루 걸음 수 7,230보
    • 정성적 데이터: 좋아하는 과목 "수학", 급식 만족도 "보통", 교복 색상 "남색", 영화 후기 "감동적이었다"

    알아보기 📌

    "만족도를 1~5점으로 매기면 정량적 데이터 아닌가요?"

    좋은 질문입니다! 숫자처럼 보여도, 1점과 2점 사이의 간격이 2점과 3점 사이의 간격과 같다고 보장할 수 없다면 본질적으로는 정성적 데이터에 가깝습니다. 다만 실무에서는 편의상 숫자로 변환하여 분석하기도 합니다. 이런 경계에 있는 데이터가 있다는 것을 기억해 두세요.

    개념 2: 구조화된 데이터 vs 비구조화된 데이터¶

    🍳 비유로 시작하기

    냉장고 정리를 떠올려 봅시다.

    • 칸칸이 정리된 냉장고: 과일은 1칸, 채소는 2칸, 음료는 3칸 — 원하는 재료를 바로 찾을 수 있음
    • 장을 보고 그냥 쑤셔 넣은 냉장고: 뒤섞여 있어서 뭐가 있는지 하나씩 꺼내봐야 함

    📖 정확한 정의

    • 구조화된 데이터(Structured Data): 행(row)과 열(column)로 깔끔하게 정리된 데이터. 엑셀 표, 데이터베이스가 대표적입니다.
    • 비구조화된 데이터(Unstructured Data): 정해진 형식이 없는 데이터. SNS 댓글, 사진, 동영상, 음성 녹음 등이 해당합니다.
    graph LR A["📊 데이터"] --> B["구조화된 데이터"] A --> C["비구조화된 데이터"] B --> B1["엑셀 성적표"] B --> B2["출석부"] B --> B3["버스 시간표"] C --> C1["SNS 댓글"] C --> C2["사진/동영상"] C --> C3["녹음 파일"]

    ✅ 예시로 확인

    • 구조화된 데이터: 학급 성적표(이름, 과목, 점수가 표로 정리), 기상청의 일별 기온 기록, 편의점 판매 내역
    • 비구조화된 데이터: 유튜브 댓글, 카카오톡 대화 내용, 수업 시간에 찍은 사진, 인터뷰 녹음 파일

    알아보기 📌

    전 세계 데이터의 약 80~90%는 비구조화된 데이터라고 합니다. 우리가 매일 쏟아내는 사진, 영상, 메시지가 대부분이기 때문이죠. 그래서 비구조화된 데이터를 분석하는 기술(텍스트 마이닝, 이미지 인식 등)이 점점 중요해지고 있습니다.

    개념 3: 데이터 수집 방법¶

    데이터를 분석하려면 먼저 모아야 합니다. 수집 방법은 크게 두 가지로 나눌 수 있습니다.

    1️⃣ 직접 수집 (1차 데이터)

    자신이 목적에 맞게 직접 모으는 데이터입니다.

    • 설문조사: 질문을 만들어 응답을 수집
    • 관찰 기록: 현상을 직접 보고 기록
    • 실험: 조건을 바꿔가며 결과를 측정
    • 인터뷰: 대상자에게 직접 이야기를 들음

    2️⃣ 간접 수집 (2차 데이터)

    다른 사람이나 기관이 이미 모아둔 데이터를 활용하는 것입니다.

    • 공공데이터포털 (data.go.kr): 정부·지자체가 공개한 데이터
    • 통계청 (kostat.go.kr): 인구, 경제 등 국가 통계
    • 논문·보고서: 연구자가 수집한 데이터
    • 웹 크롤링: 웹사이트에서 자동으로 데이터를 수집 (고급)

    생각해보기 🤔

    "우리 학교 학생들이 가장 좋아하는 급식 메뉴"를 알고 싶다면, 직접 수집과 간접 수집 중 어떤 방법이 적절할까요? 이미 급식실에서 잔반량 데이터를 기록하고 있다면 간접 수집도 가능하겠지만, 학생의 "선호도"를 정확히 알려면 설문조사(직접 수집)가 더 적절할 수 있습니다.

    개념 4: 좋은 설문조사의 조건¶

    데이터의 품질은 수집 단계에서 결정됩니다. 특히 설문조사는 질문을 어떻게 만드느냐에 따라 결과가 완전히 달라질 수 있습니다.

    나쁜 설문 문항의 특징

    • ❌ 유도 질문: "맛있는 우리 급식에 만족하시나요?" → '맛있는'이 이미 긍정적 판단을 유도
    • ❌ 이중 질문: "급식의 맛과 양에 만족하시나요?" → 맛은 좋은데 양이 부족하면 어떻게 답해야 할까요?
    • ❌ 모호한 선택지: "자주 / 가끔 / 별로" → '자주'가 일주일에 3번인지 매일인지 사람마다 다름

    좋은 설문 문항의 원칙

    • ✅ 하나의 질문에 하나의 내용만 묻기
    • ✅ 중립적인 표현 사용하기
    • ✅ 구체적인 선택지 제공하기
    • ✅ 응답자가 빠짐없이 답할 수 있는 보기 구성 (기타 항목 포함)
    graph TD A["설문 문항 작성"] --> B{"하나의 질문에<br/>하나의 내용?"} B -- "예" --> C{"중립적<br/>표현?"} B -- "아니오" --> X1["❌ 질문 분리 필요"] C -- "예" --> D{"선택지가<br/>구체적?"} C -- "아니오" --> X2["❌ 유도 표현 제거"] D -- "예" --> E["✅ 좋은 문항!"] D -- "아니오" --> X3["❌ 선택지 수정"]

    🔨 따라하기: 우리 반 등교 시간 설문조사 & 공공데이터 활용¶

    이번 실습에서는 두 가지를 해봅니다. 1. 직접 수집: 설문조사를 설계하고 데이터를 모으기 2. 간접 수집: 공공데이터포털에서 데이터를 다운로드하기

    Step 1: 설문 문항 설계하기¶

    "우리 반 학생들의 등교 패턴"을 조사하는 설문을 만들어 봅시다.

    [우리 반 등교 시간 설문조사]

Q1. 오늘 집에서 출발한 시각은? (예: 07:30)
    → 직접 입력: ___시 ___분

Q2. 주로 이용하는 등교 수단은? (하나만 선택)
    ① 도보  ② 자전거  ③ 버스  ④ 지하철  ⑤ 자가용  ⑥ 기타(        )

Q3. 집에서 학교까지 걸리는 시간은? (하나만 선택)
    ① 10분 미만  ② 10분~20분  ③ 20분~30분  ④ 30분~1시간  ⑤ 1시간 이상

Q4. 등교 시간에 대한 만족도는? (하나만 선택)
    ① 매우 불만족  ② 불만족  ③ 보통  ④ 만족  ⑤ 매우 만족

    알아보기 📌

    위 설문에서 각 문항이 어떤 유형의 데이터를 수집하는지 확인해 봅시다. - Q1 (출발 시각) → 정량적 데이터 - Q2 (등교 수단) → 정성적 데이터 (범주형) - Q3 (소요 시간) → 정량적 데이터 (구간으로 표현) - Q4 (만족도) → 정성적 데이터 (순서가 있는 범주형)

    Step 2: 데이터 수집 및 정리하기¶

    설문 응답을 받았다고 가정하고, Python으로 데이터를 만들어 정리해 봅시다.

    # 설문 응답 데이터 만들기
responses = [
    {"이름": "학생A", "출발시각": "07:30", "등교수단": "버스", "소요시간": "20분~30분", "만족도": "보통"},
    {"이름": "학생B", "출발시각": "07:45", "등교수단": "도보", "소요시간": "10분 미만", "만족도": "만족"},
    {"이름": "학생C", "출발시각": "07:15", "등교수단": "지하철", "소요시간": "30분~1시간", "만족도": "불만족"},
    {"이름": "학생D", "출발시각": "07:50", "등교수단": "자전거", "소요시간": "10분~20분", "만족도": "만족"},
    {"이름": "학생E", "출발시각": "07:20", "등교수단": "버스", "소요시간": "20분~30분", "만족도": "보통"},
]

# 데이터 출력해보기
for r in responses:
    print(f"{r['이름']}: {r['출발시각']} 출발, {r['등교수단']} 이용, {r['소요시간']}, 만족도 {r['만족도']}")

    실행 결과:

    ⚠️ 자주 하는 실수¶

    실수 1: 정량적 데이터와 정성적 데이터를 숫자 여부로만 판단하기 🔢

    "전화번호 010-1234-5678은 숫자니까 정량적 데이터다!" → ❌

    전화번호는 숫자로 되어 있지만 더하거나 평균을 낼 수 없습니다. 학번, 우편번호, 주민등록번호도 마찬가지입니다. 핵심은 "이 숫자로 계산이 의미 있는가"입니다.

    실수 2: 설문조사에서 보기가 겹치는 경우 📝

    "등교 시간이 얼마나 걸리나요? ① 10분 ② 10~20분 ③ 20~30분"

    정확히 10분이면 ①과 ②중 무엇을 골라야 할까요? 보기의 경계가 겹치면 응답자가 혼란스럽습니다. "10분 미만 / 10분 이상~20분 미만" 처럼 명확하게 구분해야 합니다.

    실수 3: 비구조화된 데이터를 바로 분석하려 하기 💬

    SNS 댓글 100개를 모았다고 바로 통계를 낼 수는 없습니다. 비구조화된 데이터는 먼저 구조화 작업(분류, 코딩, 라벨링 등)을 거쳐야 분석이 가능합니다. 예를 들어 댓글을 "긍정/부정/중립"으로 분류하는 과정이 필요합니다.
