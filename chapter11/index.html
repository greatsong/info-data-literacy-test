    11장. 우리 학교 데이터 프로젝트 — 문제 정의부터 분석까지¶

    🎯 이 장에서 배우는 것¶

    • 데이터 분석 프로세스(문제 정의→수집→정리→분석→시각화→결론) 6단계를 순서대로 설명할 수 있다
    • 학교생활과 관련된 탐구 주제를 선정하고 데이터 수집 계획서를 작성할 수 있다
    • 스프레드시트로 수집한 데이터를 정리하고 기초 분석(대푯값, 그래프)을 수행할 수 있다
    • 분석 결과에서 의미 있는 패턴이나 인사이트를 발견하고 해석할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 지금까지 스프레드시트 사용법, 데이터 정리, 시각화, 통계 개념 등을 하나하나 배워왔습니다. 마치 요리 재료 손질법, 칼 쓰는 법, 양념 만드는 법을 각각 연습한 것과 같죠.

    이제 진짜 요리를 할 시간입니다! 🍳

    이번 장에서는 배운 기술을 처음부터 끝까지 하나의 프로젝트에 통합해서 사용합니다. "우리 학교 급식 만족도는 어떨까?", "통학 시간이 학업에 영향을 줄까?" 같은 실제 궁금증을 데이터로 탐구하는 경험을 하게 됩니다.

    이 과정이 중요한 이유는 현실에서 데이터 분석이 항상 이 흐름으로 진행되기 때문입니다. 회사에서, 과학 연구에서, 정책 결정에서 — 모두 "문제 정의부터 분석까지"라는 같은 프로세스를 따릅니다.

    📚 핵심 개념¶

    개념 1: 데이터 분석 프로세스 6단계 🔄¶

    비유로 시작하기

    데이터 분석은 요리 과정과 놀라울 정도로 비슷합니다.

    • "오늘 뭐 먹지?" → 문제 정의 (무엇을 알고 싶은가?)
    • 장보기 → 데이터 수집 (필요한 재료 모으기)
    • 재료 손질 → 데이터 정리 (쓸 수 있는 형태로 다듬기)
    • 요리하기 → 데이터 분석 (평균, 비교, 패턴 찾기)
    • 예쁘게 담기 → 시각화 (그래프와 차트로 보여주기)
    • "맛있다!" 평가 → 결론 도출 (발견한 것을 정리하고 의미 해석)

    정확한 정의

    데이터 분석 프로세스란, 궁금한 문제를 데이터를 통해 체계적으로 탐구하고 답을 찾아가는 일련의 단계입니다.

    flowchart LR A["1️⃣ 문제 정의"] --> B["2️⃣ 데이터 수집"] B --> C["3️⃣ 데이터 정리"] C --> D["4️⃣ 데이터 분석"] D --> E["5️⃣ 시각화"] E --> F["6️⃣ 결론 도출"] F -.->|"새로운 궁금증 발생"| A

    💡 생각해보기: 마지막 단계에서 처음으로 돌아가는 점선 화살표가 보이나요? 분석 결과 새로운 궁금증이 생기면 다시 처음부터 시작할 수 있습니다. 이것이 데이터 분석의 반복적 특성입니다.

    예시로 확인

    "우리 반 학생들의 수면 시간은 충분할까?"라는 프로젝트를 예로 들면:

    • 문제 정의: 우리 반 학생들의 평균 수면 시간은 권장량(8~10시간)에 미치는가?
    • 데이터 수집: 설문조사로 30명의 수면 시간 데이터 확보
    • 데이터 정리: 빈칸, 이상한 응답(예: "100시간") 처리
    • 데이터 분석: 평균, 중앙값 계산, 요일별 비교
    • 시각화: 막대그래프, 히스토그램 작성
    • 결론 도출: "평일 평균 6.5시간으로 권장량에 미달, 특히 시험 기간에 더 부족"

    개념 2: 좋은 탐구 주제의 조건 🎯¶

    비유로 시작하기

    좋은 탐구 주제는 좋은 질문에서 시작합니다. "세상은 왜 존재하는가?"는 멋진 질문이지만 데이터로 답하기 어렵죠. 반면 "우리 학교 학생들은 하루에 물을 몇 잔 마실까?"는 데이터로 답할 수 있는 질문입니다.

    좋은 탐구 주제의 4가지 조건

    • 구체적: "건강"(❌) → "우리 반 학생들의 하루 수면 시간"(✅)
    • 측정 가능: 숫자나 범주로 수집할 수 있는 데이터가 있어야 함
    • 실현 가능: 2시간 안에 데이터를 모을 수 있는 범위
    • 의미 있음: 결과가 나오면 실제로 도움이 되거나 흥미로운 발견이 있음

    예시 주제 모음

    • 급식 메뉴별 만족도와 잔반량의 관계
    • 통학 수단별 소요 시간 비교
    • 시험 전후 스트레스 수준 변화
    • 교실 온도와 집중력의 관계
    • 스마트폰 사용 시간과 수면 시간의 관계

    📌 알아보기: 탐구 주제를 정할 때 "~은 ~에 영향을 줄까?"라는 형태로 만들면 분석 방향이 자연스럽게 잡힙니다. 이때 영향을 주는 것(원인 후보)을 독립변수, 영향을 받는 것(결과)을 종속변수라고 합니다.

    개념 3: 데이터 수집 계획서 📋¶

    비유로 시작하기

    여행을 떠나기 전에 일정표를 짜듯이, 데이터를 수집하기 전에 계획서를 작성합니다. 계획 없이 데이터를 모으면 "이 데이터로 뭘 하지?" 하고 막막해지기 쉽습니다.

    데이터 수집 계획서에 포함할 항목

    • 탐구 질문: 무엇을 알고 싶은가? (한 문장으로)
    • 가설(예상): 결과가 어떻게 나올 것 같은가?
    • 수집 대상: 누구에게/어디서 데이터를 모을 것인가?
    • 수집 방법: 설문조사 / 관찰 기록 / 공공데이터 활용
    • 수집 항목: 어떤 질문(열)을 포함할 것인가?
    • 일정: 언제까지 수집을 완료할 것인가?

    예시: 수면 시간 프로젝트 계획서

    • 탐구 질문: "우리 반 학생들의 평일 수면 시간은 권장량(8시간)에 미치는가?"
    • 가설: "대부분 학생들의 수면 시간이 8시간 미만일 것이다"
    • 수집 대상: 우리 반 학생 30명
    • 수집 방법: 구글 설문지(Google Forms)
    • 수집 항목: 성별, 학원 수, 취침 시각, 기상 시각, 낮 졸림 정도(1~5점)
    • 일정: 오늘 수업 중 설문 배포, 내일까지 응답 완료

    개념 4: 기초 분석과 인사이트 도출 🔍¶

    비유로 시작하기

    데이터를 모으고 정리한 것은 퍼즐 조각을 테이블 위에 펼쳐놓은 것과 같습니다. 이제 퍼즐을 맞춰서 그림을 완성해야 합니다. 기초 분석은 이 퍼즐 맞추기의 첫 단계입니다.

    기초 분석의 3가지 도구

    • 대푯값(평균, 중앙값, 최빈값): 데이터의 중심이 어디인지 파악
    • 그래프(막대, 원형, 꺾은선): 데이터의 분포와 추세를 눈으로 확인
    • 비교와 상관관계 탐색: 두 변수 사이에 관련이 있는지 살펴보기

    📌 알아보기: 인사이트(insight)란 데이터를 분석해서 발견한 "아하!" 하는 깨달음입니다. 예를 들어 "학원을 3개 이상 다니는 학생의 수면 시간이 평균 1.5시간 더 짧다"는 것은 데이터에서 발견한 인사이트입니다.

    flowchart TD A["수집된 원시 데이터"] --> B["대푯값 계산"] A --> C["그래프 작성"] A --> D["그룹별 비교"] B --> E["인사이트 도출"] C --> E D --> E E --> F["결론 및 제안"]

    🔨 따라하기: '우리 반 수면 시간' 미니 프로젝트¶

    이제 실제로 프로젝트를 처음부터 끝까지 수행해봅시다. 여기서는 예시 데이터를 사용하지만, 여러분은 실제 설문 데이터로 대체할 수 있습니다.

    Step 1: 문제 정의하기 ✏️¶

    탐구 질문을 확정합니다.

    탐구 질문: "우리 반 학생들의 평일 평균 수면 시간은 얼마이며, 학원 수와 수면 시간 사이에 관계가 있을까?"

    가설: "학원을 많이 다닐수록 수면 시간이 짧을 것이다."

    💡 생각해보기: 가설은 "틀려도 괜찮습니다!" 가설이 틀리면 그것 자체가 흥미로운 발견입니다. "학원 수와 수면 시간은 관계가 없다"는 결론도 충분히 가치 있습니다.

    Step 2: 데이터 수집하기 📊¶

    구글 스프레드시트에 아래와 같은 예시 데이터를 입력합니다. (실제 프로젝트에서는 구글 설문지로 수집한 데이터를 사용하세요.)

    A1셀부터 다음 데이터를 입력합니다:

    이름    성별    학원수    취침시각    기상시각    수면시간    졸림정도
학생1   남      1        23:00      7:00       8.0        2
학생2   여      3        0:30       6:30       6.0        4
학생3   남      2        23:30      7:00       7.5        3
학생4   여      0        22:30      7:00       8.5        1
학생5   남      3        1:00       7:00       6.0        5
학생6   여      2        23:00      6:30       7.5        3
학생7   남      1        23:30      7:00       7.5        2
학생8   여      4        1:30       7:00       5.5        5
학생9   남      2        0:00       7:00       7.0        3
학생10  여      1        23:00      7:00       8.0        2
학생11  남      3        0:30       6:30       6.0        4
학생12  여      0        22:00      7:00       9.0        1
학생13  남      2        23:30      7:00       7.5        3
학생14  여      3        1:00       6:30       5.5        5
학생15  남      1        23:00      7:00       8.0        2

    📌 알아보기: 졸림 정도는 1점(전혀 졸리지 않음)~5점(매우 졸림)의 리커트 척도로 측정했습니다. 이렇게 주관적 느낌을 숫자로 바꾸면 분석이 가능해집니다.

    Step 3: 데이터 정리하기 🧹¶

    수집된 데이터에서 문제가 없는지 확인합니다.

    확인할 3가지 체크리스트:

    • 빈칸 확인: 응답하지 않은 항목이 있는가? → 있으면 해당 행 제외 또는 별도 표시
    • 이상값 확인: 수면 시간이 0시간이나 15시간처럼 비현실적인 값은 없는가?
    • 형식 통일: 시간이 "23:00", "11pm", "23시" 등으로 섞여 있지 않은가?

    우리 예시 데이터는 이미 깔끔하지만, 실제 설문에서는 반드시 이 과정이 필요합니다.

    스프레드시트에서 빠르게 확인하는 방법:

    =COUNTA(F2:F16)       → 수면시간 열에 데이터가 몇 개인지 (15가 나와야 정상)
=MIN(F2:F16)          → 최솟값 확인 (너무 작지 않은지)
=MAX(F2:F16)          → 최댓값 확인 (너무 크지 않은지)

    Step 4: 기초 분석하기 📈¶

    이제 핵심 분석을 수행합니다. 새로운 영역(예: I열~J열)에 분석 결과를 정리합니다.

    ① 전체 대푯값 계산

    =AVERAGE(F2:F16)      → 전체 평균 수면 시간 (약 7.17시간)
=MEDIAN(F2:F16)       → 중앙값 (7.5시간)
=MIN(F2:F16)          → 최솟값 (5.5시간)
=MAX(F2:F16)          → 최댓값 (9.0시간)

    ② 학원 수별 평균 수면 시간 계산

    =AVERAGEIF(C2:C16, 0, F2:F16)    → 학원 0개인 학생의 평균 (8.75시간)
=AVERAGEIF(C2:C16, 1, F2:F16)    → 학원 1개인 학생의 평균 (8.0시간)
=AVERAGEIF(C2:C16, 2, F2:F16)    → 학원 2개인 학생의 평균 (7.38시간)
=AVERAGEIF(C2:C16, 3, F2:F16)    → 학원 3개인 학생의 평균 (5.88시간)
=AVERAGEIF(C2:C16, 4, F2:F16)    → 학원 4개인 학생의 평균 (5.5시간)

    🎉 발견! 학원 수가 늘어날수록 수면 시간이 줄어드는 경향이 뚜렷합니다. 학원 0개(8.75시간) → 4개(5.5시간)로 무려 3.25시간 차이가 납니다!

    ③ 졸림 정도와 수면 시간의 상관관계

    =CORREL(F2:F16, G2:G16)    → 상관계수 (약 -0.98)

    상관계수가 -0.98에 가깝다면, 수면 시간이 짧을수록 졸림 정도가 높다는 강한 음의 상관관계가 있습니다.

    📌 정리하기: 상관계수는 -1에서 +1 사이의 값입니다. - +1에 가까움: 하나가 증가하면 다른 것도 증가 (양의 상관) - -1에 가까움: 하나가 증가하면 다른 것은 감소 (음의 상관) - 0에 가까움: 뚜렷한 관계가 없음

    Step 5: 시각화하기 🎨¶

    분석 결과를 그래프로 만들어 한눈에 보이게 합니다.

    그래프 1: 학원 수별 평균 수면 시간 (막대그래프)

    1. Step 4에서 계산한 학원 수별 평균 데이터 영역을 선택합니다
    2. 삽입 → 차트 클릭
    3. 차트 유형을 세로 막대형으로 선택
    4. 차트 제목: "학원 수에 따른 평균 수면 시간"
    5. Y축 제목: "수면 시간(시간)", X축 제목: "학원 수(개)"

    그래프 2: 수면 시간 분포 (히스토그램)

    1. 수면시간 열(F2:F16)을 선택
    2. 삽입 → 차트 → 히스토그램 선택
    3. 차트 제목: "우리 반 수면 시간 분포"
    4. 구간을 1시간 단위로 설정

    그래프 3: 수면 시간 vs 졸림 정도 (분산형 차트)

    1. 수면시간(F열)과 졸림정도(G열)를 함께 선택
    2. 삽입 → 차트 → 분산형(산점도) 선택
    3. 차트 제목: "수면 시간과 졸림 정도의 관계"
    4. 추세선 추가 (차트 편집 → 맞춤설정 → 계열 → 추세선 체크)
    flowchart LR A["대푯값 계산 결과"] --> D["막대그래프"] B["전체 데이터 분포"] --> E["히스토그램"] C["두 변수 관계"] --> F["산점도"] D --> G["시각적 인사이트"] E --> G F --> G

    Step 6: 결론 도출하기 📝¶

    분석과 시각화를 종합하여 결론을 작성합니다. 아래 형식을 따라 작성해보세요.

    결론 작성 템플릿:

    [탐구 질문]
우리 반 학생들의 평일 평균 수면 시간은 얼마이며,
학원 수와 수면 시간 사이에 관계가 있을까?

[주요 발견]
1. 우리 반 평균 수면 시간은 7.17시간으로, 권장 수면 시간(8시간)에
   미치지 못한다.
2. 학원 수가 많을수록 수면 시간이 줄어드는 뚜렷한 경향이 있다.
   (학원 0개: 8.75시간, 4개: 5.5시간)
3. 수면 시간이 짧을수록 낮 졸림 정도가 높다.
   (상관계수: -0.98)

[가설 검증]
"학원을 많이 다닐수록 수면 시간이 짧을 것이다"
→ 데이터가 가설을 지지한다. ✅

[한계점]
- 표본이 15명으로 적어 일반화하기 어렵다.
- 수면의 '질'은 측정하지 못했다.
- 자기 보고 방식이라 정확하지 않을 수 있다.

[제안]
- 학교 차원에서 적정 수면 시간 캠페인을 진행하면 좋겠다.
- 추가 연구: 주말 수면 시간도 조사하여 비교하면 좋겠다.

    💡 생각해보기: "한계점"을 쓰는 것이 프로젝트의 질을 떨어뜨린다고 생각하나요? 오히려 반대입니다! 자신의 분석이 완벽하지 않다는 것을 인정하는 것은 정직한 과학적 태도이며, 전문가들도 반드시 한계점을 밝힙니다.

    📝 전체 코드 (스프레드시트 수식 정리)¶

    [데이터 검증]
=COUNTA(F2:F16)                    // 데이터 개수 확인
=MIN(F2:F16)                       // 최솟값
=MAX(F2:F16)                       // 최댓값

[전체 대푯값]
=AVERAGE(F2:F16)                   // 평균
=MEDIAN(F2:F16)                    // 중앙값

[조건별 평균 (AVERAGEIF)]
=AVERAGEIF(C2:C16, 0, F2:F16)     // 학원 0개 평균
=AVERAGEIF(C2:C16, 1, F2:F16)     // 학원 1개 평균
=AVERAGEIF(C2:C16, 2, F2:F16)     // 학원 2개 평균
=AVERAGEIF(C2:C16, 3, F2:F16)     // 학원 3개 평균
=AVERAGEIF(C2:C16, 4, F2:F16)     // 학원 4개 평균

[상관관계]
=CORREL(F2:F16, G2:G16)           // 두 변수의 상관계수

[성별 비교 (추가 분석)]
=AVERAGEIF(B2:B16, "남", F2:F16)  // 남학생 평균 수면시간
=AVERAGEIF(B2:B16, "여", F2:F16)  // 여학생 평균 수면시간

    ⚠️ 자주 하는 실수¶

    실수 1: 결론을 먼저 정하고 데이터를 끼워 맞추기 🚫

    "학원이 나쁘다는 걸 증명해야지!"라고 먼저 결론을 정하면, 반대되는 데이터를 무시하게 됩니다. 데이터가 가설과 다른 결과를 보여주면 그것도 중요한 발견입니다. 데이터에 정직해야 합니다.

    실수 2: 상관관계를 인과관계로 착각하기 🚫

    "학원 수가 많으면 수면 시간이 짧다"(상관관계)와 "학원 때문에 잠을 못 잔다"(인과관계)는 다릅니다. 학원을 많이 다니는 학생이 원래 늦게 자는 성향일 수도 있습니다. "A와 B는 관련이 있다"라고 표현하되, "A가 B의 원인이다"라고 단정하지 마세요.

    실수 3: 데이터 정리 없이 바로 분석하기 🚫

    빈칸이나 이상값을 처리하지 않으면 평균이 크게 왜곡됩니다. 예를 들어 누군가 수면 시간에 실수로 "80"을 입력했다면, 평균이 크게 올라가 전체 결과가 엉망이 됩니다. 정리 단계를 절대 건너뛰지 마세요!

    실수 4: 한 가지 그래프만 보고 판단하기 🚫

    막대그래프만으로는 개별 데이터의 분포를 알 수 없고, 산점도만으로는 전체 평균을 파악하기 어렵습니다. 여러 종류의 그래프를 함께 활용해야 데이터를 입체적으로 이해할 수 있습니다.
