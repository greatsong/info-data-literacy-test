    Chapter 1. 정보란 무엇일까? — 데이터, 정보, 지식의 차이¶

    Part 1 · [1권] 정보의 세계로 들어가기 · 예상 소요 시간: 2시간

    🎯 이 장에서 배우는 것¶

    • 데이터, 정보, 지식의 개념을 구분하고 각각의 관계를 설명할 수 있다
    • 일상생활에서 데이터가 정보로 변환되는 과정을 사례를 통해 설명할 수 있다
    • 정보의 가치와 활용 목적에 따라 같은 데이터가 다르게 해석될 수 있음을 이해한다
    • 간단한 파이썬 코드로 데이터를 정보로 변환하는 과정을 체험할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    오늘 아침 일기예보에서 "기온 3°C"라고 했습니다. 이 숫자는 데이터일까요, 정보일까요?

    여러분은 매일 엄청난 양의 숫자, 글자, 이미지를 만납니다. 스마트폰 알림, 급식 메뉴표, 시험 점수표, SNS의 좋아요 수…

    그런데 이 모든 것이 같은 종류는 아닙니다. 어떤 것은 그냥 숫자 덩어리이고, 어떤 것은 의미 있는 메시지이며, 어떤 것은 행동을 이끌어내는 깊은 이해입니다.

    이 세 가지를 구분할 수 있으면, 앞으로 정보 기술을 배울 때 "컴퓨터가 실제로 무엇을 하고 있는지" 명확하게 이해할 수 있습니다. 이것이 정보 교육의 첫 번째 열쇠 🔑 입니다.

    📚 핵심 개념¶

    개념 1: 데이터(Data) — 아직 의미가 없는 날것¶

    1. 비유로 시작 🧩

    데이터는 퍼즐 조각 하나와 같습니다. 조각 하나만 보면 전체 그림이 무엇인지 알 수 없죠. "3"이라는 숫자만 놓여 있다면, 이것이 온도인지 사과 개수인지 학년인지 알 수 없습니다.

    2. 정확한 정의

    데이터(Data) 란 가공되지 않은 사실이나 수치로, 그 자체만으로는 특별한 의미를 전달하지 않는 원시적(raw) 형태의 값입니다.

    3. 예시로 확인

    • 3 — 숫자일 뿐, 무엇을 뜻하는지 모름
    • 김치찌개 — 단어일 뿐, 어디에서 왜 나온 건지 모름
    • 128 — 시험 점수? 키? 몸무게?

    개념 2: 정보(Information) — 맥락을 만난 데이터¶

    1. 비유로 시작 🖼️

    퍼즐 조각 여러 개를 올바른 위치에 맞추면 그림의 일부가 보이기 시작합니다. "아, 이건 바다 그림이구나!" — 이렇게 의미가 드러나는 순간, 데이터는 정보가 됩니다.

    2. 정확한 정의

    정보(Information) 란 데이터를 특정 맥락(context) 속에서 처리·정리하여 의미와 쓸모를 갖게 만든 것입니다.

    3. 예시로 확인

    • 오늘 아침 서울의 기온은 3°C입니다 → 숫자 3에 장소, 시간, 단위라는 맥락이 붙었습니다
    • 내일 급식 메뉴: 김치찌개, 불고기, 샐러드 → 단어들에 날짜, 용도가 붙어 정보가 되었습니다
    • 수학 시험 평균 점수 72점 → 숫자 72에 과목, 종류, 집단 맥락이 부여되었습니다

    개념 3: 지식(Knowledge) — 정보를 이해하고 활용하는 힘¶

    1. 비유로 시작 🧠

    완성된 퍼즐 그림을 보고 "이건 제주도 바다인데, 여름에 가면 좋겠다"라고 판단하고 계획을 세우는 것 — 이것이 지식입니다. 정보를 경험과 결합하여 새로운 판단이나 행동으로 이어지는 단계입니다.

    2. 정확한 정의

    지식(Knowledge) 란 정보를 학습·경험·분석을 통해 내면화하여, 새로운 상황에서 판단하고 행동할 수 있는 능력입니다.

    3. 예시로 확인

    • "기온 3°C이니까 패딩을 입고 나가야겠다" → 기온 정보 + 생활 경험 = 행동 판단
    • "우리 반 수학 평균이 72점이고, 지난 시험보다 낮아졌으니 복습 시간을 늘려야겠다" → 정보 비교 + 학습 경험 = 전략 수립

    개념 4: 세 가지의 관계 — 피라미드 구조¶

    데이터, 정보, 지식은 아래에서 위로 올라가는 계단형 관계를 이룹니다.

    graph BT D["🧩 데이터<br/>날것의 사실·수치<br/>예: 3, 김치찌개, 128"] I["🖼️ 정보<br/>맥락이 부여된 데이터<br/>예: 오늘 기온 3°C"] K["🧠 지식<br/>정보 + 경험 → 판단·행동<br/>예: 패딩을 입고 나가자"] D -->|"맥락 부여<br/>(처리·정리)"| I I -->|"경험·학습<br/>(내면화)"| K style D fill:#FFF3E0,stroke:#FF9800,color:#000 style I fill:#E3F2FD,stroke:#2196F3,color:#000 style K fill:#E8F5E9,stroke:#4CAF50,color:#000

    알아보기 📖

    이 구조를 DIKW 피라미드라고 부릅니다. D(Data) → I(Information) → K(Knowledge) 순서로, 위로 갈수록 양은 줄어들고 가치는 높아집니다. 맨 꼭대기에는 W(Wisdom, 지혜)가 있는데, 이것은 지식을 바탕으로 옳고 그름까지 판단하는 단계입니다.

    🔨 따라하기: 데이터를 정보로 바꿔보자!¶

    급식 데이터를 파이썬으로 처리하여 의미 있는 정보로 만들어보는 실습입니다.

    Step 1: 날것의 데이터 준비하기¶

    아래는 일주일 동안의 급식 메뉴 데이터입니다. 아직 정리되지 않은 상태입니다.

    # Step 1: 날것의 데이터 — 그냥 나열된 목록
meals = [
    "월,김치찌개,불고기,샐러드",
    "화,된장찌개,생선구이,나물",
    "수,카레라이스,탕수육,샐러드",
    "목,김치찌개,닭갈비,과일",
    "금,비빔밥,미역국,샐러드"
]

print("=== 날것의 데이터 ===")
for m in meals:
    print(m)

    이 상태에서는 "이번 주에 김치찌개가 몇 번 나오지?" 같은 질문에 바로 답하기 어렵습니다.

    Step 2: 데이터를 처리하여 정보 만들기¶

    맥락을 부여해 봅시다. "이번 주에 각 메뉴가 몇 번 등장하는지" 세어보겠습니다.

    # Step 2: 데이터 처리 → 정보 생성
menu_count = {}

for m in meals:
    parts = m.split(",")     # 쉼표로 나누기
    day = parts[0]            # 첫 번째는 요일
    dishes = parts[1:]        # 나머지는 메뉴

    for dish in dishes:
        if dish in menu_count:
            menu_count[dish] = menu_count[dish] + 1
        else:
            menu_count[dish] = 1

print("=== 처리된 정보: 메뉴별 등장 횟수 ===")
for dish, count in menu_count.items():
    print(f"  {dish}: {count}회")

    실행 결과 (예상):

    === 처리된 정보: 메뉴별 등장 횟수 ===
  김치찌개: 2회
  불고기: 1회
  샐러드: 3회
  된장찌개: 1회
  ...

    이제 "샐러드가 3번으로 가장 자주 나오는구나!"라는 정보를 얻었습니다.

    Step 3: 정보에서 지식으로 — 판단 내리기¶

    # Step 3: 정보를 바탕으로 판단(지식) 생성
most_frequent = max(menu_count, key=menu_count.get)
least_frequent_list = [
    dish for dish, count in menu_count.items() if count == 1
]

print("=== 지식: 판단과 제안 ===")
print(f"  가장 자주 나오는 메뉴: {most_frequent} ({menu_count[most_frequent]}회)")
print(f"  한 번만 나온 메뉴: {', '.join(least_frequent_list)}")
print(f"  → 제안: '{most_frequent}'의 빈도를 줄이고 다양성을 높이면 좋겠습니다.")

    생각해보기 🤔

    마지막 print의 "제안"은 프로그램이 스스로 생각한 것일까요? 아닙니다! 사람이 "자주 나오는 메뉴는 줄이는 게 좋다"라는 규칙(지식)을 코드로 넣어준 것입니다. 컴퓨터는 데이터를 정보로 바꾸는 처리 도구이고, 지식은 여전히 사람의 영역입니다.

    📝 전체 코드¶

    아래 코드를 복사하여 한 번에 실행할 수 있습니다.

    # ============================================
# Chapter 1: 데이터 → 정보 → 지식 체험하기
# ============================================

# ----- Step 1: 날것의 데이터 -----
meals = [
    "월,김치찌개,불고기,샐러드",
    "화,된장찌개,생선구이,나물",
    "수,카레라이스,탕수육,샐러드",
    "목,김치찌개,닭갈비,과일",
    "금,비빔밥,미역국,샐러드"
]

print("=== 날것의 데이터 ===")
for m in meals:
    print(f"  {m}")
print()

# ----- Step 2: 데이터 처리 → 정보 -----
menu_count = {}

for m in meals:
    parts = m.split(",")
    dishes = parts[1:]
    for dish in dishes:
        if dish in menu_count:
            menu_count[dish] = menu_count[dish] + 1
        else:
            menu_count[dish] = 1

print("=== 처리된 정보: 메뉴별 등장 횟수 ===")
for dish, count in menu_count.items():
    print(f"  {dish}: {count}회")
print()

# ----- Step 3: 정보 → 지식(판단) -----
most_frequent = max(menu_count, key=menu_count.get)
least_frequent_list = [
    dish for dish, count in menu_count.items() if count == 1
]

print("=== 지식: 판단과 제안 ===")
print(f"  가장 자주 나오는 메뉴: {most_frequent} ({menu_count[most_frequent]}회)")
print(f"  한 번만 나온 메뉴: {', '.join(least_frequent_list)}")
print(f"  → 제안: '{most_frequent}'의 빈도를 줄이고 다양성을 높이면 좋겠습니다.")

    ⚠️ 자주 하는 실수¶

    실수 1: "숫자는 무조건 데이터다"라고 생각하기 ❌¶

    "서울 기온 3°C" 처럼 맥락이 포함된 숫자는 이미 정보입니다. 핵심은 숫자 자체가 아니라 맥락이 있느냐 없느냐입니다.

    • 3 → 데이터 (맥락 없음)
    • 오늘 서울 기온 3°C → 정보 (시간·장소·단위라는 맥락 있음)

    실수 2: 정보와 지식을 같은 것으로 혼동하기 ❌¶

    "수학 평균 72점"은 정보이지, 지식이 아닙니다. "평균이 떨어졌으니 공부 방법을 바꿔야지"라는 판단과 행동 계획이 붙어야 지식이 됩니다.

    • 정보: 사실을 알려주는 것 📋
    • 지식: 사실을 바탕으로 행동할 수 있는 것 🎯

    실수 3: "데이터가 많으면 자동으로 좋은 정보가 된다"고 생각하기 ❌¶

    데이터가 아무리 많아도 잘못 처리하거나 엉뚱한 맥락을 붙이면 쓸모없거나 틀린 정보가 됩니다. 예를 들어 체육 수행평가 점수를 국어 성적으로 잘못 입력하면, 데이터 양은 같지만 정보의 질은 엉망이 됩니다.

    ✅ 스스로 점검하기¶

    기본 문제 (개념 확인)¶

    문제 1. 다음 중 데이터에 해당하는 것을 모두 고르세요.

    • ① 42
    • ② 오늘 부산의 미세먼지 농도는 "좋음"입니다
    • ③ 빨강
    • ④ 매일 30분 운동하면 건강에 좋다

    정답: ①, ③

    ② 는 장소·시간·대상이 포함된 정보, ④ 는 경험과 연구에 기반한 지식입니다.

    문제 2. 빈칸을 채우세요.

    데이터에 _____을(를) 부여하면 정보가 되고, 정보에 _____과(와) 학습을 더하면 지식이 된다.

    정답: 맥락(context), 경험

    응용 문제¶

    문제 3. 아래 세 문장을 데이터 → 정보 → 지식 순서로 배열하세요.

    • (가) "우산을 챙겨 나가야겠다."
    • (나) "오후 강수확률 90%"
    • (다) "90"

    정답: (다) 데이터 → (나) 정보 → (가) 지식

    심화 문제 (도전!)¶

    문제 4. 아래 뉴스 기사 문장에서 데이터, 정보, 지식에 해당하는 부분을 각각 찾아 분류해 보세요.

    "지난달 전국 평균 기온은 2.1°C로, 평년(3.5°C)보다 1.4°C 낮았다. 기상청은 한파가 지속될 것으로 예상하며, 농작물 동해 피해 예방을 위해 보온 조치를 권고했다."

    정답 예시 - 데이터: 2.1, 3.5, 1.4 (숫자 자체) - 정보: "지난달 전국 평균 기온 2.1°C", "평년보다 1.4°C 낮았다" (맥락이 부여된 사실) - 지식: "한파 지속 예상", "농작물 보온 조치 권고" (정보를 분석하여 판단·행동 제시)

    🚀 더 해보기¶

    도전 과제 1: 나만의 데이터 → 정보 → 지식 사례 만들기¶

    일상생활에서 데이터 → 정보 → 지식의 3단계를 거치는 사례를 하나 찾아 아래 형식으로 정리해 보세요.

    • 데이터: (예: 85, 92, 78)
    • 정보: (예: 이번 학기 영어 세 번의 시험 점수는 85점, 92점, 78점이다)
    • 지식: (예: 마지막 시험에서 점수가 떨어졌으니 문법 파트를 다시 복습해야겠다)

    도전 과제 2: 코드 변형하기¶

    전체 코드에서 meals 리스트를 여러분 학교의 이번 주 실제 급식 메뉴로 바꿔서 실행해 보세요. 가장 자주 나오는 메뉴는 무엇인가요?

    도전 과제 3: 같은 데이터, 다른 정보¶

    "SNS 게시물의 좋아요 수: 150"이라는 데이터를 두 가지 다른 관점에서 정보로 만들어 보세요.

    • 관점 A (게시물 작성자): ?
    • 관점 B (광고 마케터): ?

    힌트: 같은 숫자라도 누가, 왜 보느냐에 따라 전혀 다른 정보가 됩니다. 이것이 "정보의 가치는 맥락에 따라 달라진다"는 이 장의 핵심 메시지입니다.

    🔗 다음 장으로¶

    정리하기 📌

    이번 장에서 우리는 세 가지 핵심을 배웠습니다.

    • 데이터는 맥락 없는 날것의 사실·수치입니다
    • 정보는 데이터에 맥락(누가·언제·어디서·왜)을 부여한 것입니다
    • 지식은 정보에 경험과 판단을 더해 행동으로 이어지는 힘입니다

    그리고 같은 데이터라도 맥락에 따라 다른 정보가 될 수 있다는 것을 확인했습니다.
