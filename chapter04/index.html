    Chapter 4. 디지털 시민의 권리와 책임 — 저작권, 개인정보, 디지털 윤리¶

    🎯 이 장에서 배우는 것¶

    • 저작권의 개념을 이해하고, 왜 보호해야 하는지 설명할 수 있다
    • CCL(크리에이티브 커먼즈 라이선스) 마크를 읽고 올바르게 활용할 수 있다
    • 개인정보의 범위를 파악하고 디지털 환경에서 보호하는 방법을 실천할 수 있다
    • 디지털 시민으로서 지켜야 할 윤리적 원칙을 사례 기반으로 판단할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔 친구가 찍은 사진을 허락 없이 내 SNS에 올린 적이 있나요? 인터넷에서 찾은 멋진 그림을 내 발표 자료에 그냥 복사해 넣은 적은요?

    우리는 매일 디지털 세상에서 정보를 만들고, 나누고, 소비합니다. 유튜브 영상을 보고, 인스타그램에 사진을 올리고, 검색한 자료로 과제를 합니다. 그런데 이 모든 활동에는 권리와 책임이 따릅니다.

    내가 밤새워 만든 영상을 누군가 이름도 안 밝히고 가져다 썼다면 어떤 기분일까요? 내 전화번호가 모르는 사람에게 퍼졌다면요? 디지털 시민이란, 디지털 세상에서 살아가는 우리 모두를 뜻합니다. 좋은 디지털 시민이 되려면 다른 사람의 권리를 존중하고, 내 권리도 지킬 줄 알아야 합니다.

    이 장을 마치면 여러분은 인터넷에서 정보를 올바르게 이용하고, 자신의 개인정보를 안전하게 보호하며, 디지털 세상에서 책임감 있게 행동하는 방법을 갖추게 됩니다.

    📚 핵심 개념¶

    개념 1: 저작권 — "내 작품에 붙은 보이지 않는 자물쇠" 🔒¶

    ① 비유로 시작

    여러분이 한 달 동안 정성 들여 그린 그림이 있다고 상상해 보세요. 어느 날 누군가 그 그림을 사진 찍어 자기 작품이라고 올렸습니다. 억울하지 않나요? 저작권은 바로 이런 상황을 막기 위해 존재합니다. 작품을 만든 순간, 보이지 않는 자물쇠가 자동으로 채워지는 것이죠.

    ② 정확한 정의

    저작권(Copyright) 이란, 사람의 생각이나 감정을 창작적으로 표현한 결과물(저작물)에 대해 만든 사람(저작자)에게 주어지는 법적 권리입니다.

    핵심 포인트를 정리하면 다음과 같습니다.

    • 자동 발생: 별도 등록 없이 만든 순간부터 보호됩니다
    • 보호 대상: 글, 음악, 그림, 사진, 영상, 소프트웨어 등
    • 보호 기간: 저작자 사망 후 70년까지 (한국 기준)
    • 아이디어는 보호하지 않음: 표현된 형태만 보호합니다

    ③ 예시로 확인

    • ✅ 저작권 보호 대상: 내가 쓴 시, 직접 작곡한 노래, 찍은 사진
    • ❌ 저작권 보호 대상 아님: "고양이를 주제로 그림을 그리자"라는 아이디어 자체, 역사적 사실 데이터
    graph LR A["🎨 창작물 탄생"] --> B["🔒 저작권 자동 발생"] B --> C["📋 저작자에게 권리 부여"] C --> D["복제권: 복사할 권리"] C --> E["공연권: 공개 발표 권리"] C --> F["전송권: 인터넷 공유 권리"] C --> G["2차적저작물작성권: 변형 권리"]

    알아보기 📌 "유튜브 영상에서 배경음악을 아무 노래나 써도 되나요?" — 안 됩니다! 음악도 저작권 보호 대상입니다. 저작권자의 허락 없이 사용하면 영상이 삭제되거나 법적 문제가 생길 수 있습니다. 유튜브의 '오디오 라이브러리'처럼 무료로 제공되는 음원을 활용하세요.

    개념 2: CCL — "이 조건이면 써도 좋아요" 라는 약속표 📋¶

    ① 비유로 시작

    도서관 책에 "관내 열람만 가능", "대출 가능", "복사 가능" 같은 스티커가 붙어 있다고 상상해 보세요. CCL(Creative Commons License) 은 인터넷 세상에서 저작물에 붙이는 이런 스티커입니다. 저작자가 "이 조건만 지켜주면 자유롭게 써도 돼!"라고 미리 알려주는 것이죠.

    ② 정확한 정의

    CCL(크리에이티브 커먼즈 라이선스) 은 저작자가 자신의 저작물을 다른 사람이 일정 조건 하에 자유롭게 이용할 수 있도록 허락하는 표준화된 라이선스 체계입니다.

    CCL은 4가지 기본 조건의 조합으로 이루어집니다.

    • BY (저작자표시): 원작자의 이름을 반드시 밝혀야 합니다 — 모든 CCL에 기본 포함
    • NC (비영리): 돈을 벌기 위한 목적으로는 사용할 수 없습니다
    • ND (변경금지): 원본을 수정하거나 변형할 수 없습니다
    • SA (동일조건변경허락): 변형은 가능하지만, 같은 CCL 조건을 적용해야 합니다

    ③ 예시로 확인

    graph TD A["CCL 4가지 조건"] --> BY["BY 저작자표시<br/>👤 이름 꼭 밝히기"] A --> NC["NC 비영리<br/>🚫💰 돈벌이 금지"] A --> ND["ND 변경금지<br/>🚫✂️ 수정 금지"] A --> SA["SA 동일조건변경허락<br/>🔄 같은 조건 유지"]

    이 4가지 조건이 조합되어 6가지 유형의 CCL이 만들어집니다.

    • CC BY → 이름만 밝히면 자유롭게 사용 (가장 자유로움)
    • CC BY-SA → 이름 밝히기 + 같은 조건으로 공유
    • CC BY-NC → 이름 밝히기 + 비영리 목적만
    • CC BY-NC-SA → 이름 밝히기 + 비영리 + 같은 조건
    • CC BY-ND → 이름 밝히기 + 변경 불가
    • CC BY-NC-ND → 이름 밝히기 + 비영리 + 변경 불가 (가장 제한적)

    생각해보기 🤔 위키백과의 글은 CC BY-SA 라이선스입니다. 이 글을 학교 신문에 싣는다면, 어떤 조건을 지켜야 할까요? 정답: 원작자(위키백과)를 밝히고, 신문 기사도 같은 CC BY-SA 조건을 적용해야 합니다.

    개념 3: 개인정보 보호 — "나만의 디지털 울타리" 🛡️¶

    ① 비유로 시작

    집 주소, 전화번호, 일기장 내용을 학교 게시판에 붙여놓을 수 있나요? 당연히 싫겠죠. 그런데 인터넷에서는 이런 일이 자기도 모르게 일어나곤 합니다. 개인정보 보호는 디지털 세상에서 나만의 울타리를 세우는 것입니다.

    ② 정확한 정의

    개인정보란, 살아 있는 개인에 관한 정보로서 이름, 주민등록번호, 영상 등을 통하여 개인을 알아볼 수 있는 정보를 말합니다. (개인정보 보호법 제2조)

    어떤 것들이 개인정보에 해당할까요?

    • 직접 식별 정보: 이름, 주민등록번호, 여권번호, 얼굴 사진
    • 연락 정보: 전화번호, 이메일, 집 주소
    • 디지털 정보: 아이디, 비밀번호, IP 주소, 쿠키(cookie) 정보
    • 민감 정보: 건강 정보, 종교, 정치적 성향
    • 결합 시 식별 가능 정보: 학교 + 학년 + 반 + 번호 → 특정 개인 식별 가능!

    ③ 예시로 확인 — 실제 사례

    사례 분석 📰 2023년, 한 온라인 쇼핑몰에서 약 25만 명의 고객 정보(이름, 연락처, 주소)가 유출되는 사건이 있었습니다. 해커가 관리자 계정의 취약한 비밀번호를 뚫고 들어간 것이 원인이었습니다. 유출된 정보는 스팸 전화, 피싱 문자 등에 악용되었고, 해당 기업은 수억 원의 과징금을 부과받았습니다.

    graph LR A["😈 해커"] -->|"취약한 비밀번호 공격"| B["🖥️ 서버 침투"] B --> C["📋 개인정보 탈취"] C --> D["📱 스팸/피싱 악용"] C --> E["💳 금융 사기"] C --> F["🕵️ 신원 도용"]

    개념 4: 디지털 윤리 — "화면 너머에도 사람이 있다" 🤝¶

    ① 비유로 시작

    교실에서 친구에게 직접 말하지 못할 말을 온라인 메시지로는 쉽게 보내본 적 있나요? 화면이라는 벽 뒤에 숨으면 용기가 커지기도 하지만, 화면 너머에도 감정을 가진 사람이 있다는 것을 잊기 쉽습니다. 디지털 윤리는 '오프라인에서 하지 않을 행동은 온라인에서도 하지 않는다'는 원칙입니다.

    ② 정확한 정의

    디지털 윤리란, 디지털 기술과 인터넷을 사용할 때 지켜야 할 도덕적 원칙과 행동 기준을 말합니다.

    디지털 시민이 지켜야 할 핵심 원칙을 알아봅시다.

    • 존중: 다른 사람의 의견, 저작물, 개인정보를 존중합니다
    • 책임: 내가 올린 글과 공유한 정보에 책임을 집니다
    • 정직: 거짓 정보를 만들거나 퍼뜨리지 않습니다
    • 배려: 사이버 폭력(악플, 따돌림, 허위 소문)을 하지 않습니다
    • 참여: 잘못된 정보나 유해한 콘텐츠를 발견하면 신고합니다

    ③ 예시로 확인 — 디지털 윤리 딜레마

    상황 1: 단체 채팅방에서 친구 A의 어색한 사진이 돌아다닙니다. 웃기긴 한데... 공유 버튼을 누를까요? → ❌ A의 초상권(자기 얼굴이 함부로 사용되지 않을 권리)과 감정을 침해합니다.

    상황 2: 시험 기간에 검색하다가 정답이 유출된 파일을 발견했습니다. 다운로드할까요? → ❌ 부정행위이며, 유출된 자료를 퍼뜨리면 법적 책임까지 질 수 있습니다.

    정리하기 📌 디지털 세상의 핵심 규칙 4가지를 기억하세요: 저작권(남의 창작물 존중), CCL(허락 조건 확인), 개인정보 보호(나와 남의 정보 지키기), 디지털 윤리(화면 너머의 사람 존중).

    🔨 따라하기: CCL 이미지를 찾아 올바르게 사용하기¶

    학교 발표 자료를 만들 때, 인터넷에서 이미지를 어떻게 합법적으로 가져오는지 실습합니다.

    Step 1: CCL 이미지 검색 사이트 접속¶

    웹 브라우저를 열고 크리에이티브 커먼즈 검색 사이트에 접속합니다.

    https://search.creativecommons.org

    이 사이트는 CCL이 적용된 무료 이미지, 음악 등을 검색할 수 있는 공식 도구입니다.

    Step 2: 원하는 이미지 검색¶

    검색창에 발표 주제와 관련된 키워드를 영어로 입력합니다.

    예시 검색어: "digital citizenship"

    검색 결과가 나오면, 각 이미지 아래에 CCL 마크가 표시됩니다. 이 마크를 확인하는 것이 핵심입니다.

    Step 3: CCL 조건 확인하고 적절한 이미지 선택¶

    검색된 이미지를 클릭하면 라이선스 정보가 표시됩니다.

    예시: CC BY 2.0
→ BY: 저작자 이름만 밝히면 자유롭게 사용 가능!

예시: CC BY-NC-ND 4.0  
→ BY: 저작자 표시 필수
→ NC: 비영리만 가능 (학교 과제 = 비영리 ✅)
→ ND: 이미지 수정 불가 (자르거나 필터 적용 ❌)

    알아보기 📌 학교 발표는 비영리 목적이므로 NC 조건이 붙어도 사용 가능합니다. 하지만 ND(변경금지) 조건이 있으면 이미지 크롭(자르기)이나 색상 변경도 할 수 없다는 점에 주의하세요.

    Step 4: 이미지 다운로드 및 출처 기록¶

    이미지를 다운로드한 뒤, 반드시 다음 정보를 기록합니다.

    기록할 정보:
- 작품 제목: "Digital Citizens Working Together"
- 저작자: Jane Smith
- 출처 URL: https://www.flickr.com/photos/example/12345
- 라이선스: CC BY 2.0

    Step 5: 발표 자료에 올바른 출처 표기¶

    발표 자료(PPT, 문서 등)에 이미지를 삽입한 뒤, 이미지 아래 또는 자료 마지막 페이지에 출처를 표기합니다.

    출처 표기 형식:

"Digital Citizens Working Together" by Jane Smith
(CC BY 2.0)
출처: https://www.flickr.com/photos/example/12345

    Step 6: 비밀번호 보안 점검 (보너스 실습)¶

    개인정보 보호 실천으로, 자신의 비밀번호 보안 수준을 점검해 봅시다.

    아래 체크리스트로 자가 진단합니다.

    나의 비밀번호 보안 체크리스트:

□ 8자리 이상인가?
□ 영문 대·소문자를 섞었는가?
□ 숫자를 포함하고 있는가?
□ 특수문자(!@#$ 등)를 포함하고 있는가?
□ 이름, 생일, 전화번호 등 개인정보를 포함하지 않았는가?
□ 서비스마다 다른 비밀번호를 사용하는가?
□ 2단계 인증을 설정했는가?

결과:
- 7개 전부 체크 → 🏆 철벽 보안!
- 5~6개 체크 → 👍 양호, 부족한 부분 보완하세요
- 4개 이하 → ⚠️ 위험! 지금 바로 비밀번호를 변경하세요

    알아보기 📌 — 2단계 인증이란? 비밀번호 입력 후 추가로 본인 확인을 하는 보안 방법입니다. 문자 인증번호, 인증 앱(Google Authenticator 등), 생체 인식(지문, 얼굴) 등이 있습니다. 비밀번호가 유출되어도 2단계 인증이 있으면 계정을 보호할 수 있습니다.

    기본 문제¶

    문제 1. 다음 중 저작권으로 보호받을 수 없는 것은?

    A. 내가 쓴 소설
B. 직접 작곡한 멜로디
C. "우주를 배경으로 게임을 만들자"는 아이디어
D. 내가 찍은 풍경 사진

    정답: C — 아이디어 자체는 보호 대상이 아니며, 표현된 결과물만 보호됩니다.

    문제 2. CCL 마크 CC BY-NC 가 적용된 음악을 사용할 수 있는 경우는?

    A. 유튜브 광고 수익 영상의 배경음악으로 사용
B. 학교 축제 UCC 영상에 출처를 밝히고 사용
C. 원곡 멜로디를 바꿔서 내 노래처럼 판매
D. 출처 없이 팟캐스트에 삽입

    정답: B — 학교 축제 영상은 비영리(NC 조건 충족)이며, 출처를 밝혔으므로(BY 조건 충족) 올바른 사용입니다.
