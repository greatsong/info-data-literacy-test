    Chapter 9. 상관관계와 인과관계 — 데이터로 관계 읽기¶

    Part 3 | [2권] 데이터 분석과 활용 · 12차시 중 9차시

    🎯 이 장에서 배우는 것¶

    • 상관관계와 인과관계의 차이를 명확히 구분하고 실생활 사례로 설명할 수 있다
    • 산점도를 활용하여 두 변수 간의 상관관계(양의 상관, 음의 상관, 무상관)를 시각적으로 판단할 수 있다
    • 허위 상관(spurious correlation)의 사례를 분석하고, 데이터 해석 시 주의할 점을 서술할 수 있다
    • Python으로 산점도를 직접 그리고 상관관계의 방향과 강도를 해석할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🍦

    "아이스크림 판매량이 늘면 익사 사고도 늘어난다."

    이 문장만 보면, 아이스크림이 위험한 식품처럼 느껴지지 않나요? 그렇다면 아이스크림 판매를 금지하면 익사 사고가 줄어들까요?

    당연히 아닙니다. 아이스크림 판매량과 익사 사고는 여름이라는 공통 원인 때문에 함께 증가할 뿐, 하나가 다른 하나를 일으키는 것이 아닙니다.

    뉴스에서 "A가 증가하면 B도 증가한다"라는 보도를 자주 봅니다. 하지만 함께 움직인다(상관관계)는 것과 원인이 된다(인과관계)는 것은 전혀 다른 이야기입니다. 이 차이를 모르면 잘못된 판단을 내리고, 엉뚱한 대책을 세우게 됩니다.

    이 장을 마치면 데이터 속 두 변수의 관계를 정확히 읽고, 섣부른 인과 주장에 비판적으로 대응할 수 있습니다.

    📚 핵심 개념¶

    개념 1: 상관관계 — "함께 움직이는 두 시소"¶

    🎪 비유로 시작

    놀이터에 나란히 놓인 두 개의 시소를 상상해 보세요. 바람이 불면 두 시소가 같은 방향으로 움직이기도 하고, 반대 방향으로 움직이기도 합니다. 중요한 점은, 두 시소가 서로 줄로 연결된 것은 아니라는 것입니다. 그저 같은 바람의 영향을 받을 뿐이죠.

    📖 정확한 정의

    상관관계(Correlation)란 두 변수가 함께 변하는 경향을 말합니다.

    • 양의 상관(Positive Correlation): 한 변수가 커지면 다른 변수도 커지는 경향 → 예) 키가 크면 신발 사이즈도 큰 편
    • 음의 상관(Negative Correlation): 한 변수가 커지면 다른 변수는 작아지는 경향 → 예) 결석 일수가 많으면 시험 성적이 낮은 편
    • 무상관(No Correlation): 두 변수 사이에 뚜렷한 패턴이 없음 → 예) 혈액형과 수학 성적
    graph LR subgraph 양의 상관 A1["변수 A ↑"] --> B1["변수 B ↑"] end subgraph 음의 상관 A2["변수 A ↑"] --> B2["변수 B ↓"] end subgraph 무상관 A3["변수 A ↑"] --> B3["변수 B ?"] end

    ✅ 예시로 확인

    • 공부 시간 ↑ → 시험 성적 ↑ (양의 상관)
    • 운동량 ↑ → 체지방률 ↓ (음의 상관)
    • 좋아하는 색깔 → 달리기 기록 (무상관)

    개념 2: 인과관계 — "도미노가 쓰러지듯"¶

    🎪 비유로 시작

    이번엔 도미노를 떠올려 보세요. 첫 번째 도미노를 밀면 두 번째가 쓰러지고, 두 번째가 세 번째를 쓰러뜨립니다. 여기서는 원인(첫 도미노)이 결과(다음 도미노)를 직접 일으킵니다.

    시소(상관관계)는 "같은 바람에 반응할 뿐"이고, 도미노(인과관계)는 "하나가 다른 하나를 직접 쓰러뜨리는 것"입니다.

    📖 정확한 정의

    인과관계(Causation)란 한 변수(원인)가 다른 변수(결과)를 직접적으로 일으키는 관계입니다.

    인과관계가 성립하려면 다음 조건이 필요합니다: - 시간 순서: 원인이 결과보다 먼저 일어나야 함 - 함께 변함: 원인이 변하면 결과도 변해야 함 - 다른 설명 배제: 제3의 변수가 아닌, 실제로 원인이 결과를 만들어야 함

    ✅ 예시로 확인

    • 약을 복용했더니 열이 내렸다 → 약이 원인, 열 감소가 결과 (인과관계 가능성 높음)
    • 우산을 들고 다니는 사람이 많은 날 교통사고도 많다 → 우산이 사고를 일으킨 것이 아니라, 비가 공통 원인 (인과관계 아님!)

    정리하기 📌

    • 상관관계 = "A와 B가 함께 움직인다" (방향만 알려줌)
    • 인과관계 = "A가 B를 일으킨다" (원인과 결과의 방향이 있음)
    • 모든 인과관계는 상관관계를 포함하지만, 상관관계가 곧 인과관계는 아닙니다!

    개념 3: 산점도 — 관계를 눈으로 보는 도구¶

    🎪 비유로 시작

    학급 친구들의 키와 몸무게를 칠판에 점 하나씩 찍는다고 상상해 보세요. 가로축에 키, 세로축에 몸무게를 놓으면, 점들이 모여서 오른쪽 위로 올라가는 띠 모양이 됩니다. 이것이 산점도(scatter plot)입니다.

    📖 정확한 정의

    산점도(Scatter Plot)는 두 변수의 값을 좌표 평면 위에 점으로 표시한 그래프입니다. 점들의 분포 패턴을 보면 상관관계의 방향(양/음)과 강도(강함/약함)를 직관적으로 파악할 수 있습니다.

    ✅ 판단 기준

    • 점들이 오른쪽 위로 모여 있으면 → 양의 상관
    • 점들이 오른쪽 아래로 모여 있으면 → 음의 상관
    • 점들이 흩어져 있으면 → 무상관
    • 점들이 가상의 직선에 가까이 모여 있을수록 → 강한 상관

    개념 4: 허위 상관 — 데이터의 함정¶

    🎪 비유로 시작

    어떤 마을에서 황새 둥지 수와 신생아 출생률이 함께 증가한다는 데이터가 있다고 합시다. "황새가 아기를 데려온다"는 결론이 맞을까요? 물론 아닙니다. 마을 인구가 늘면 집이 많아지고(황새 둥지도 늘고), 사람이 많으니 출생도 늘어난 것입니다.

    📖 정확한 정의

    허위 상관(Spurious Correlation)이란 실제로는 인과관계가 없는데, 우연이나 숨겨진 제3의 변수(교란 변수) 때문에 두 변수가 관련 있는 것처럼 보이는 현상입니다.

    graph TD Z["🌡️ 제3의 변수<br/>여름 (기온)"] --> X["🍦 아이스크림 판매량 ↑"] Z --> Y["🏊 익사 사고 ↑"] X -.->|"허위 상관<br/>(직접 관계 없음)"| Y style Z fill:#FFE66D,color:#333 style X fill:#4ECDC4,color:#fff style Y fill:#FF6B6B,color:#fff

    ✅ 재미있는 허위 상관 사례들

    • 니콜라스 케이지 출연 영화 수 ↔ 수영장 익사 사고 수 (상관계수 0.67!)
    • 미국 치즈 소비량 ↔ 침대 시트에 얽혀 사망하는 사고 수
    • 해적 수 감소 ↔ 지구 평균 기온 상승

    이 사례들은 tylervigen.com/spurious-correlations 사이트에서 더 확인할 수 있습니다.

    알아보기 🔍

    허위 상관이 위험한 이유는, 그럴듯한 숫자 뒤에 숨어 잘못된 정책이나 판단을 유도할 수 있기 때문입니다. "데이터가 보여준다"는 말에 바로 설득당하지 않는 비판적 사고력이 필요합니다.

    🔨 따라하기: Python으로 산점도 그리고 상관관계 확인하기¶

    이번 실습에서는 가상의 학생 데이터를 만들어 산점도를 그리고, 상관관계를 직접 눈으로 확인합니다.

    Step 1: 데이터 준비하기¶

    수면 시간과 시험 성적이라는 두 변수를 가진 데이터를 만들어봅시다.

    import matplotlib.pyplot as plt
import random

# 재현 가능하도록 시드 설정
random.seed(42)

# 가상 데이터: 학생 20명의 수면 시간과 시험 성적
sleep_hours = [round(random.uniform(4, 9), 1) for _ in range(20)]
# 수면 시간이 길수록 성적이 높은 경향 + 약간의 랜덤 노이즈
test_scores = [round(h * 8 + random.uniform(-10, 10), 1) for h in sleep_hours]

print("수면 시간:", sleep_hours[:5], "...")
print("시험 성적:", test_scores[:5], "...")

    알아보기 🔍

    random.uniform(4, 9)은 4부터 9 사이의 실수를 무작위로 생성합니다. 실제 데이터가 없을 때 가상 데이터(시뮬레이션)를 만들어 분석하는 것은 데이터 과학에서 자주 사용하는 방법입니다.

    Step 2: 산점도 그리기¶

    plt.figure(figsize=(8, 5))
plt.scatter(sleep_hours, test_scores, color='steelblue', s=80, alpha=0.7)
plt.xlabel('Sleep Hours', fontsize=12)
plt.ylabel('Test Score', fontsize=12)
plt.title('Sleep Hours vs Test Score', fontsize=14)
plt.grid(True, alpha=0.3)
plt.show()

    실행하면 오른쪽 위로 올라가는 점들의 패턴이 보일 것입니다. 이것이 바로 양의 상관입니다!

    Step 3: 상관관계의 강도를 숫자로 확인하기¶

    산점도로 눈으로 확인했다면, 이번엔 상관계수(correlation coefficient)로 강도를 숫자로 확인합니다.

    # 상관계수 직접 계산 (외부 라이브러리 없이)
n = len(sleep_hours)
mean_x = sum(sleep_hours) / n
mean_y = sum(test_scores) / n

numerator = sum((x - mean_x) * (y - mean_y) for x, y in zip(sleep_hours, test_scores))
denom_x = sum((x - mean_x) ** 2 for x in sleep_hours) ** 0.5
denom_y = sum((y - mean_y) ** 2 for y in test_scores) ** 0.5

correlation = numerator / (denom_x * denom_y)
print(f"상관계수: {correlation:.2f}")

    상관계수의 해석 기준은 다음과 같습니다:

    • +0.7 ~ +1.0: 강한 양의 상관
    • +0.3 ~ +0.7: 약한 양의 상관
    • -0.3 ~ +0.3: 거의 무상관
    • -0.7 ~ -0.3: 약한 음의 상관
    • -1.0 ~ -0.7: 강한 음의 상관

    Step 4: 세 가지 상관관계를 한눈에 비교하기¶

    양의 상관, 음의 상관, 무상관 데이터를 각각 만들어 나란히 비교해봅시다.

    random.seed(42)

# 양의 상관: 공부 시간 vs 성적
study = [round(random.uniform(1, 8), 1) for _ in range(30)]
grade = [round(s * 10 + random.uniform(-5, 5), 1) for s in study]

# 음의 상관: 게임 시간 vs 성적
game = [round(random.uniform(0, 6), 1) for _ in range(30)]
grade2 = [round(90 - g * 8 + random.uniform(-5, 5), 1) for g in game]

# 무상관: 신발 사이즈 vs 성적
shoe = [round(random.uniform(230, 280), 0) for _ in range(30)]
grade3 = [round(random.uniform(40, 100), 1) for _ in range(30)]

fig, axes = plt.subplots(1, 3, figsize=(15, 4))

axes[0].scatter(study, grade, color='#4ECDC4', s=60)
axes[0].set_title('Positive Correlation', fontsize=12)
axes[0].set_xlabel('Study Hours')
axes[0].set_ylabel('Grade')

axes[1].scatter(game, grade2, color='#FF6B6B', s=60)
axes[1].set_title('Negative Correlation', fontsize=12)
axes[1].set_xlabel('Game Hours')
axes[1].set_ylabel('Grade')

axes[2].scatter(shoe, grade3, color='#95A5A6', s=60)
axes[2].set_title('No Correlation', fontsize=12)
axes[2].set_xlabel('Shoe Size')
axes[2].set_ylabel('Grade')

plt.tight_layout()
plt.show()

    random.seed(7)

print("아이스크림 vs 익사 상관계수:", end=" ")
# 간단한 상관계수 계산 함수
def calc_corr(x, y):
    n = len(x)
    mx, my = sum(x)/n, sum(y)/n
    num = sum((a-mx)*(b-my) for a,b in zip(x,y))
    dx = sum((a-mx)**2 for a in x)**0.5
    dy = sum((b-my)**2 for b in y)**0.5
    return num/(dx*dy)

print(f"{calc_corr(icecream, drowning):.2f}")
print(f"기온 vs 익사 상관계수: {calc_corr(temperature, drowning):.2f}")

    ⚠️ 자주 하는 실수¶

    실수 1: "상관관계 = 인과관계"로 착각하기 🚫

    "데이터를 보니 A가 오르면 B도 오르니까, A가 B의 원인이야!"라고 단정짓는 실수입니다. 상관관계는 인과관계의 '단서'일 뿐, 증거가 아닙니다. 항상 "혹시 제3의 변수가 있지 않을까?"라고 먼저 의심하세요.

    실수 2: 상관계수만 보고 관계를 판단하기 🚫

    상관계수가 0에 가까워도 비선형 관계(곡선 패턴)가 존재할 수 있습니다. 예를 들어, 운동 시간과 건강의 관계는 U자 곡선(너무 안 해도, 너무 많이 해도 좋지 않음)일 수 있는데, 상관계수는 이런 패턴을 잡지 못합니다. 반드시 산점도를 먼저 그려서 눈으로 확인하세요.

    실수 3: 인과관계의 방향을 뒤집기 🚫

    "소방차가 많이 출동할수록 화재 피해가 크다. 그러니 소방차를 줄이자!" — 원인과 결과를 뒤집은 오류입니다. 화재가 크기 때문에 소방차가 많이 출동하는 것이지, 소방차가 화재를 키우는 것이 아닙니다. "누가 먼저인가?"를 항상 따져보세요.
