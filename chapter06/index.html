    챕터 6: 데이터 정리의 기술 — 스프레드시트 기초¶

    Part 2 | [1권] 데이터 리터러시의 기초

    🎯 이 장에서 배우는 것¶

    • 스프레드시트의 기본 인터페이스와 용어(셀, 행, 열, 시트)를 이해하고 사용할 수 있다
    • 수집한 데이터를 스프레드시트에 체계적으로 입력하고 정렬·필터 기능을 활용할 수 있다
    • 기본 함수(SUM, AVERAGE, COUNT, MAX, MIN)를 사용하여 데이터를 요약할 수 있다
    • 함수 결과를 예측하고, 새로운 데이터에 함수를 적용할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    선생님이 시험 성적표를 나눠주셨는데, 이름 순서도 아니고 번호 순서도 아닌 뒤죽박죽 상태라면? "내 점수가 평균보다 높을까?" "우리 반에서 가장 높은 점수는?" 이런 질문에 답하려면 한참을 들여다봐야 할 것입니다.

    데이터를 '모으는 것'과 데이터를 '정리하는 것'은 완전히 다른 일입니다. 아무리 좋은 데이터를 수집해도, 정리되지 않으면 아무것도 알아낼 수 없습니다.

    스프레드시트는 이런 문제를 해결하는 가장 기본적이고 강력한 도구입니다. 전 세계 직장인의 약 80% 이상이 업무에서 스프레드시트를 사용한다는 통계가 있을 정도로, 데이터를 다루는 사람이라면 반드시 익혀야 할 기술입니다.

    이번 장에서는 이전 차시에서 수집한 등교 시간 데이터를 직접 스프레드시트에 입력하고, 정렬하고, 함수로 요약하는 과정을 함께 해보겠습니다.

    📚 핵심 개념¶

    개념 1: 스프레드시트란? — 디지털 모눈종이 📊¶

    비유로 시작하기

    미술 시간에 사용하는 모눈종이를 떠올려 보세요. 가로줄과 세로줄이 교차하면서 수많은 작은 칸이 만들어지죠? 스프레드시트는 바로 이 모눈종이의 디지털 버전입니다. 다만, 이 디지털 모눈종이에는 특별한 능력이 있습니다. 칸에 숫자를 넣으면 자동으로 계산해주고, 순서를 바꿔달라고 하면 한 번에 정렬해주죠.

    정확한 정의

    스프레드시트(Spreadsheet)는 데이터를 행과 열로 이루어진 표 형태로 입력·저장·계산·분석할 수 있는 프로그램입니다.

    대표적인 스프레드시트 프로그램은 다음과 같습니다.

    • 마이크로소프트 엑셀(Excel): 가장 널리 사용되는 유료 프로그램
    • 구글 시트(Google Sheets): 무료, 웹 브라우저에서 바로 사용 가능
    • 한셀, 리브레오피스 Calc 등: 기능이 거의 동일한 대안 프로그램

    알아보기 💡

    이 장에서는 누구나 무료로 사용할 수 있는 구글 시트를 기준으로 설명합니다. 엑셀도 화면 구성과 함수가 거의 동일하니, 엑셀을 사용해도 그대로 따라할 수 있습니다.

    개념 2: 셀, 행, 열, 시트 — 스프레드시트의 기본 용어 🏗️¶

    비유로 시작하기

    아파트 주소를 생각해 보세요. "102동 305호"라고 하면 정확히 어떤 집인지 알 수 있죠? 스프레드시트에서도 모든 칸에는 고유한 주소가 있습니다.

    정확한 정의

    graph TD A["🗂️ 스프레드시트 기본 용어"] --> B["📦 셀 Cell"] A --> C["↔️ 행 Row"] A --> D["↕️ 열 Column"] A --> E["📄 시트 Sheet"] B --> B1["하나의 칸<br/>데이터를 입력하는 최소 단위"] C --> C1["가로 한 줄<br/>숫자 1, 2, 3...으로 표시"] D --> D1["세로 한 줄<br/>알파벳 A, B, C...로 표시"] E --> E1["하나의 작업 공간<br/>탭으로 여러 시트 전환"]

    각 용어를 자세히 살펴봅시다.

    • 열(Column): 세로 방향 줄입니다. 맨 위에 A, B, C, D... 알파벳이 붙어 있습니다. 열은 보통 데이터의 "종류"를 나타냅니다. (예: A열 = 이름, B열 = 등교 시간)
    • 행(Row): 가로 방향 줄입니다. 왼쪽에 1, 2, 3, 4... 숫자가 붙어 있습니다. 행은 보통 하나의 "데이터 항목"을 나타냅니다. (예: 2행 = 김철수의 데이터)
    • 셀(Cell): 열과 행이 만나는 한 칸입니다. 셀 주소는 "열 알파벳 + 행 숫자"로 표현합니다. 예를 들어, B3은 B열과 3행이 만나는 칸입니다.
    • 시트(Sheet): 화면 아래 탭으로 전환할 수 있는 하나의 작업 공간입니다. 한 파일 안에 여러 시트를 만들 수 있습니다.

    예시로 확인

    아래와 같이 등교 시간 데이터가 입력되어 있다고 상상해 봅시다.

    • A1 셀에는 "이름"이라는 제목이 들어있습니다
    • B1 셀에는 "등교 시간(분)"이라는 제목이 들어있습니다
    • A2 셀에는 "김철수", B2 셀에는 "15"가 들어있습니다
    • A3 셀에는 "이영희", B3 셀에는 "25"가 들어있습니다

    정리하기 📌

    셀 주소를 읽는 법: 항상 열(알파벳)이 먼저, 행(숫자)이 나중입니다. "B3"은 "B열 3행"을 뜻합니다. 이것은 앞으로 함수를 쓸 때 매우 중요한 규칙입니다!

    개념 3: 정렬과 필터 — 데이터를 원하는 대로 배치하기 🔄¶

    비유로 시작하기

    도서관에서 책을 찾을 때를 생각해 보세요. 책이 가나다순으로 정리되어 있으면 쉽게 찾을 수 있지만, 아무렇게나 꽂혀 있으면 하루 종일 찾아야 할 수도 있습니다. 정렬은 책을 가나다순으로 꽂는 것이고, 필터는 "소설 책만 보여줘"라고 하는 것과 같습니다.

    정확한 정의

    • 정렬(Sort): 데이터를 특정 기준에 따라 순서대로 나열하는 기능
    • 오름차순(ㄱ→ㅎ, 1→100): 작은 것에서 큰 것으로

    • 내림차순(ㅎ→ㄱ, 100→1): 큰 것에서 작은 것으로

    • 필터(Filter): 특정 조건에 맞는 데이터만 골라서 보여주는 기능

    • 예: 등교 시간이 20분 이상인 학생만 보기
    • 원본 데이터를 삭제하지 않고, 화면에서 숨기는 것

    예시로 확인

    등교 시간 데이터를 정렬하면 이런 변화가 생깁니다.

    • 정렬 전: 김철수(15분) → 이영희(25분) → 박민수(10분) → 최지은(30분)
    • 오름차순 정렬 후: 박민수(10분) → 김철수(15분) → 이영희(25분) → 최지은(30분)

    필터를 사용하면 "등교 시간 20분 이상인 학생만 보기"처럼 조건을 걸 수 있습니다. 이때 박민수와 김철수의 데이터는 삭제되지 않고 화면에서 임시로 숨겨질 뿐입니다.

    개념 4: 기본 함수 — 스프레드시트의 마법 주문 ✨¶

    비유로 시작하기

    마법사가 주문을 외우면 마법이 일어나듯, 스프레드시트에서 함수(Function)는 특정 명령어를 입력하면 자동으로 계산이 이루어지는 마법 주문입니다. "이 숫자들을 다 더해줘!"라고 일일이 말하는 대신, SUM이라는 주문 한 마디면 끝!

    정확한 정의

    함수는 =함수이름(범위) 형태로 작성합니다. 반드시 등호(=)로 시작해야 합니다.

    다섯 가지 기본 함수를 알아봅시다.

    • SUM(범위): 범위 안의 숫자를 모두 더합니다 → "합계"
    • AVERAGE(범위): 범위 안의 숫자의 평균을 구합니다 → "평균값"
    • COUNT(범위): 범위 안에서 숫자가 들어있는 셀의 개수를 셉니다 → "몇 개?"
    • MAX(범위): 범위 안에서 가장 큰 값을 찾습니다 → "최댓값"
    • MIN(범위): 범위 안에서 가장 작은 값을 찾습니다 → "최솟값"
    graph LR A["=SUM(B2:B6)"] --> B["B2부터 B6까지<br/>모든 숫자를 더해라"] C["함수 구조"] --> D["= 등호<br/>함수 시작 신호"] C --> E["함수이름<br/>어떤 계산?"] C --> F["(범위)<br/>어디부터 어디까지?"]

    예시로 확인

    B2부터 B6까지 등교 시간 데이터가 15, 25, 10, 30, 20(분)이라면

    • =SUM(B2:B6) → 100 (전부 더한 합계)
    • =AVERAGE(B2:B6) → 20 (평균)
    • =COUNT(B2:B6) → 5 (숫자가 있는 셀 5개)
    • =MAX(B2:B6) → 30 (가장 큰 값)
    • =MIN(B2:B6) → 10 (가장 작은 값)

    알아보기 💡

    B2:B6에서 콜론(:)은 "~부터 ~까지"라는 뜻입니다. "B2에서 B6까지 모든 셀"을 의미합니다. 이것을 범위(Range)라고 부릅니다.

    🔨 따라하기¶

    이전 차시에서 수집한 등교 시간 데이터를 스프레드시트에 입력하고, 정렬·필터·함수를 활용해 봅시다.

    📋 준비물: 컴퓨터 또는 태블릿, 구글 계정(구글 시트 사용 시)

    Step 1: 구글 시트 열기 🖥️¶

    1. 웹 브라우저에서 sheets.google.com에 접속합니다
    2. 구글 계정으로 로그인합니다
    3. 화면 왼쪽 위의 "+"(빈 스프레드시트) 를 클릭합니다
    4. 제목을 클릭하여 "우리 반 등교 시간 데이터"로 변경합니다

    생각해보기 🤔

    화면에 보이는 A, B, C... 알파벳과 1, 2, 3... 숫자가 바로 열과 행입니다. 아무 셀이나 클릭해 보세요. 왼쪽 위 이름 상자에 그 셀의 주소(예: D7)가 표시되는 것을 확인할 수 있습니다.

    Step 2: 데이터 입력하기 ⌨️¶

    아래 데이터를 직접 입력해 봅시다. (이전 차시에서 수집한 자신의 데이터가 있다면 그것을 사용하세요!)

    입력 방법: 셀을 클릭한 뒤 내용을 타이핑하고, Tab 키를 누르면 오른쪽 셀로, Enter 키를 누르면 아래 셀로 이동합니다.

    입력할 데이터는 다음과 같습니다.

    A1에 "이름", B1에 "등교 시간(분)", C1에 "교통수단"을 입력합니다. 이것이 머리글(헤더)입니다.

    그 아래로 데이터를 입력합니다. - 2행: 김철수 / 15 / 도보 - 3행: 이영희 / 25 / 버스 - 4행: 박민수 / 10 / 자가용 - 5행: 최지은 / 30 / 버스 - 6행: 정하늘 / 20 / 자전거 - 7행: 한소율 / 35 / 버스 - 8행: 오준서 / 12 / 도보 - 9행: 강예린 / 22 / 자가용 - 10행: 윤시우 / 18 / 도보 - 11행: 서다온 / 28 / 버스

    정리하기 📌

    데이터 입력 규칙 3가지를 기억하세요! 1. 1행은 항상 머리글(제목)로 사용합니다 2. 한 열에는 같은 종류의 데이터만 넣습니다 (B열은 전부 숫자) 3. 빈 행이나 빈 열 없이 빈틈없이 채웁니다

    Step 3: 정렬 실습하기 🔢¶

    등교 시간이 짧은 학생부터 긴 학생 순서로 정렬해 봅시다.

    1. B1 셀을 클릭합니다 (등교 시간 열의 머리글)
    2. 상단 메뉴에서 데이터(Data) → 시트 정렬 기준 → 열 B 기준 A→Z(오름차순) 을 선택합니다
    3. 데이터가 등교 시간이 짧은 순서(10분 → 35분)로 재배열된 것을 확인합니다

    💡 엑셀 사용자: 데이터 탭 → 정렬 버튼을 사용하면 동일한 기능을 수행할 수 있습니다.

    확인: 정렬 후 가장 위(2행)에 박민수(10분)가, 가장 아래(11행)에 한소율(35분)이 있어야 합니다.

    Step 4: 필터 실습하기 🔍¶

    버스를 타고 오는 학생만 골라서 봅시다.

    1. A1 셀을 클릭합니다
    2. 상단 메뉴에서 데이터(Data) → 필터 만들기(Create a filter) 를 선택합니다
    3. 머리글(1행)의 각 셀에 작은 삼각형(▼) 아이콘이 생긴 것을 확인합니다
    4. C1 셀의 삼각형(▼)을 클릭합니다
    5. "전체 선택 해제"를 한 뒤, "버스"에만 체크합니다
    6. 확인을 누릅니다

    결과: 이영희(25분), 최지은(30분), 한소율(35분), 서다온(28분) — 버스를 타는 학생 4명만 화면에 표시됩니다!

    필터를 해제하려면: C1의 삼각형을 다시 클릭하고 "전체 선택"을 체크한 뒤 확인을 누릅니다.

    Step 5: 기본 함수 사용하기 🧮¶

    이제 함수를 사용하여 데이터를 요약해 봅시다. 먼저 필터를 해제하고, 13행부터 요약 정보를 입력합니다.

    A13에 "합계"를 입력하고, B13 셀에 다음 함수를 입력합니다.

    =SUM(B2:B11)

    Enter를 누르면 215가 표시됩니다. (모든 학생의 등교 시간 합계)

    같은 방법으로 나머지 함수도 입력합니다.

    • A14에 "평균", B14에 =AVERAGE(B2:B11) → 결과: 21.5
    • A15에 "인원수", B15에 =COUNT(B2:B11) → 결과: 10
    • A16에 "최대", B16에 =MAX(B2:B11) → 결과: 35
    • A17에 "최소", B17에 =MIN(B2:B11) → 결과: 10

    생각해보기 🤔

    B14 셀에 표시된 21.5라는 숫자가 의미하는 것은 무엇일까요? "우리 반 학생들은 평균적으로 약 21.5분을 등교에 사용한다"는 뜻입니다. 이렇게 함수를 사용하면 데이터에서 의미 있는 정보를 빠르게 뽑아낼 수 있습니다.

    Step 6: 데이터 수정과 자동 업데이트 확인하기 🔄¶

    함수의 진짜 마법을 확인해 봅시다.

    1. 박민수의 등교 시간(현재 10분)을 40분으로 수정합니다
    2. B13~B17의 함수 결과가 자동으로 바뀌는 것을 관찰합니다
    3. 합계: 215 → 245
    4. 평균: 21.5 → 24.5
    5. 최대: 35 → 40 (최댓값이 바뀜!)

    6. 최소: 10 → 12 (최솟값도 바뀜!)

    7. 확인이 끝나면 다시 10으로 되돌려 놓습니다

    알아보기 💡

    이것이 스프레드시트의 가장 강력한 장점입니다. 데이터가 바뀌면 함수 결과가 자동으로 재계산됩니다. 계산기로 일일이 다시 계산할 필요가 없습니다!

    📝 전체 코드¶

    이번 장에서 사용한 모든 함수를 정리합니다. 아래 함수를 스프레드시트에 복사하여 바로 사용할 수 있습니다.

    =SUM(B2:B11)          → 합계 구하기
=AVERAGE(B2:B11)      → 평균 구하기
=COUNT(B2:B11)        → 숫자 셀 개수 세기
=MAX(B2:B11)          → 최댓값 찾기
=MIN(B2:B11)          → 최솟값 찾기

    함수 작성 규칙 요약

    • 반드시 = (등호)로 시작
    • 함수 이름은 대문자·소문자 모두 가능 (sum과 SUM은 같음)
    • 범위는 콜론(:)으로 시작 셀과 끝 셀을 연결 (B2:B11)
    • 괄호를 반드시 닫기 — 열고 닫지 않으면 오류 발생

    ⚠️ 자주 하는 실수¶

    실수 1: 등호(=)를 빼먹는다 ❌¶

    SUM(B2:B11)     ← 이렇게 쓰면 텍스트로 인식됨 (계산 안 됨)
=SUM(B2:B11)    ← 이렇게 등호를 반드시 붙여야 함 ✅

    등호가 없으면 스프레드시트는 이것을 "그냥 글자"로 인식합니다. 셀에 SUM(B2:B11)이라는 텍스트가 그대로 표시되므로, 함수가 작동하지 않습니다.

    실수 2: 범위에 머리글을 포함한다 ❌¶

    =AVERAGE(B1:B11)  ← B1은 "등교 시간(분)"이라는 텍스트! 오류 가능
=AVERAGE(B2:B11)  ← 데이터만 포함해야 정확한 결과 ✅

    B1에는 "등교 시간(분)"이라는 글자가 들어 있습니다. 숫자가 아닌 것이 범위에 포함되면 함수가 오류를 내거나 잘못된 결과를 계산합니다.

    실수 3: 빈 행을 사이에 두고 데이터를 입력한다 ❌¶

    예를 들어 5행을 비워두고 7행부터 데이터를 이어 쓰면, 정렬이나 필터를 적용할 때 빈 행 아래 데이터가 무시될 수 있습니다. 데이터는 항상 빈틈 없이 연속으로 입력하세요.

    실수 4: 괄호를 닫지 않는다 ❌¶

    =SUM(B2:B11      ← 닫는 괄호 ) 가 없음! 오류 발생
=SUM(B2:B11)     ← 정상 ✅

    괄호를 열었으면 반드시 닫아야 합니다. 스프레드시트가 빨간색으로 오류를 표시하면 괄호를 확인하세요.
